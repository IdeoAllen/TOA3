## 4. 状态与象限

| 状态 | 含义 |
|------|------|
| `todo` | 未开始 |
| `doing` | 进行中 |
| `blocked` | 等主理人点验/拍板 |
| `parked` | 暂缓 |
| `done` | 已完成 |

象限：`Q1` 重要紧急 · `Q2` 重要不紧急 · `Q3` 紧急不重要 · `Q4` 其它
