## 1. 用户场景（必填）

| 项 | 内容 |
|----|------|
| 谁 | 教务/培训运营（开班前招兼职助教） |
| 何时 | 开班信息已定（班级名 + 场地地址），要发微信群 / 朋友圈 / 招聘群 |
| 输入 | 班级名称（规范：`课程-城市-开始YYYYMMDD-结束YYYYMMDD`）、工作地址；可选调日薪（默认 150） |
| 输出 | 按公司固定模板填好的招聘稿纯文本；主路径一键复制；可选落盘 txt |
| 失败体验 | 班级名解析失败 → 人话指出缺哪段（城市/日期），允许手工补字段后仍能出稿；地址空 → 禁止空地址出稿 |

**示例**

- 班级名称：`销售主管岗位L1-成都-20260915-20260917`
- 工作地址：`成都市高新区新园南一路2号成都三和阿维塔`
- 期望拆出：城市=成都；培训时间=2026年9月15日–2026年9月17日；天数=3；执行费=450（150×3）

**模板骨架（公司口径 · 固定段）**

```
【城市】诚聘兼职助教
培训时间：【开始日期】-【结束日期】   8:00-18:30
地点：【地址】
工资：（不含餐）
1、  布场50（培训前一天下午大约3个小时）
2、  培训【天数】天执行费用【费用】（150一天）
工作内容：新能源汽车培训助教
1、  教室布置
2、  学员签到
3、  协助讲师进行课堂互动
4、  拍摄课堂照片和视频素材
5、  管理培训车辆
6、  管理文具及教学物料
要求：吃苦耐劳，积极主动，服从安排，及时回复消息，有责任心，需着商务装，女生长发扎马尾辫，化淡装
```

**边界（硬）**

| 做 | 不做 |
|----|------|
| 班级名结构化解析 → 填模板 | 通用「AI 写招聘文案」/ 多岗位模板市场 |
| 固定公司话术 + 可变字段校对 | 海报 / 图片设计（创客贴类） |
| 复制优先；可选归档 txt | Boss/智联发布对接；简历筛选（已有 resume_*） |

## 3. 取长补短（服务亮点，不是抄功能表）

| 维度 | 手改旧帖 | 海报工具 | 通用 AI/文案公式 | **我们可偷师 / 必须避开** |
|------|----------|----------|------------------|---------------------------|
| 核心流程 | 复制上次再改 | 选模板填图 | 提示词出散文 | 偷：秒出可发；避：重设计/重创意 |
| 交互 | 零学习、易错 | 重视觉 | 不可控口径 | 偷：复制即发；避：让运营「润色」固定段 |
| 能力深度 | 无校验 | 无班级语义 | 无培训班命名 | **钉班级命名 → 天数/费用** |
| 俗套 | 无产品 | 「一键美图」 | 「智能文案」 | 不自称智能招聘 |

### 可偷师（至少 3 条）

1. 主路径必须「出稿就能贴出去」（复制优先，不是先保存再找文件）  
2. 失败时允许手工补字段，不堵死  
3. 可变数字（天数、日薪、费用）要可见、可改、改完即时重算  

### 明确不学 / 否决

1. AI 自由发挥改写职责/着装要求  
2. 海报排版、花哨营销标题  
3. 对接招聘平台发帖

## 3.2 设计亮点挖掘（产品角度 · 必填）

| 候选亮点（一句话） | 为何不落俗套 | 可感知？ | 可测？ | 入选 §3.5？ |
|--------------------|--------------|----------|--------|-------------|
| **班级命名即表单**：标准班级名拆城市/起止日/天数/费用 | 不是又一个空白模板填空；钉的是运营已有命名规范 | 是 | 是 | **是 → #1** |
| **公司话术骨架锁定**：固定段不可散装改写，仅可变字段可校对重渲 | 对抗「智能润色」；卖的是对外口径一致 | 是 | 是 | **是 → #2** |
| **复制即发优先**：主按钮生成并复制；可选落盘 | 招聘场景终点是「发出去」，不是「归档完」 | 是 | 是 | **是 → #3** |
| 从培训交付看板预填班级名 | 串链加分，非本功能独到本体 | 中 | 是 | **否**（实现可做，不作 §3.5） |
| AI 智能生成吸睛招聘文案 | 会改公司固定要求，俗套且危险 | 弱 | 否 | **否** |
| 一键生成招聘海报 | 错位到设计工具 | — | — | **否** |
| 统一体验 / 好看界面 | 平台通例 | 弱 | — | **否** |
| show_saved / 打开目录 | 平台铁律 | 是 | 是 | **否**（不作独到） |

### 俗套否决清单

| 俗套说法 | 本功能为何不用它当独到 |
|----------|------------------------|
| 「一键 / 智能 / AI 写招聘」 | 口径必须锁死；吹智能会改写固定段 |
| 「统一体验 / 界面好看」 | 主题与控件库通例 |
| 「本地优先」 | 全产品通例 |
| 「show_saved / 打开目录」 | 平台铁律 |
| 「海量模板 / 海报设计」 | 不是我们的场；错位给创客贴 |

## 3.5 三个独到之处（与主理人共创 · 门禁核心）

| # | 独到主张（一句话） | 用户可感知价值 | 可测验收 | 论证结论 |
|---|--------------------|----------------|----------|----------|
| 1 | **班级命名即表单**：粘贴 `课程-城市-YYYYMMDD-YYYYMMDD` 即拆出城市、起止日、天数与执行费（日薪×天数） | 不用再手算培训几天、费用多少 | 示例班名 → 成都 / 3 天 / 450；非法班名给人话错误且可手工补 | 已确认 |
| 2 | **公司话术骨架锁定**：布场/职责/着装等固定段只读可预览；仅城市、日期、地址、天数、日薪、费用可改后重渲 | 发出去的字与公司模板一致，不被「润色」带跑 | 改地址/日薪后重渲，固定段字节级不变 | 已确认 |
| 3 | **复制即发优先**：主操作「生成并复制」；结果区可直接贴群；可选另存 txt | 开班前 30 秒内能发出招聘帖 | 生成后剪贴板内容与结果区一致；无地址不出稿 | 已确认 |

共创纪要：

- 日薪默认 150，费用 = 天数 × 日薪；日薪可改则费用跟算。  
- 日期展示：`2026年9月15日`。  
- 进页读取 `class_session_handoff` 预填班级名（非独到处）。

## 4. 技术方案（过门才写码）

| 项 | 结论 |
|----|------|
| 选定栈 / 库 | 纯 Python 解析 + PySide6 页；无联网、无 LLM |
| 否决项及原因 | 否决 AI 文案、海报导出、招聘平台 API |
| 架构落点 | `modules/assistant_recruit_post/` 页面 + service；菜单 `group: business`；可选用 `class_session_handoff` 预填 |
| 性能约束 | 解析与渲染同步即可（毫秒级）；禁进页联网 |
| 品质验收 | 示例数据出稿正确；复制一致；非法班名可补字段；固定段不可被 UI 改写 |
| 如何兑现 §3.5 | #1 service 解析；#2 模板常量 + 可变字段表单；#3 Primary「生成并复制」+ 可选 show_saved |
