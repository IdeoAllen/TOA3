## 1. 用户场景（必填）

| 项 | 内容 |
|----|------|
| 谁 | 办公室人员：桌面上堆着合同/截图/草稿，想先进 TOA 看一眼再决定要不要记一笔 |
| 何时 | 从资源管理器/桌面把文件拖到 **TOA 图标**或已开主窗；或关联打开（可选后续） |
| 输入 | 一个或多个本地文件路径（MVP：图 + 文本；夹可进目录） |
| 输出 | 唤起 TOA → 进「MACOS风格桌面」；**根 = 文件父目录**；选中并预览；**「导入记事本」需再点一下** |
| 失败体验 | 路径无效/不可读 → 状态栏警告，仍进桌面（上次根或系统桌面）；不弹阻塞对话框 |

### 主理人已裁定（对话 2026-09-03）

- **A**：只进 macOS 桌面浏览/预览，导入记事要再点一下  
- 拖入时 **永远「以文件父目录为根」**（多文件同父：该父；跨父：以第一个文件父为根并提示其余）

## 3. 取长补短矩阵

| 维度 | 资源管理器打开 | Dropzone | Everything+预览 | **TOA 采纳** |
|------|----------------|----------|-----------------|--------------|
| 入口 | 拖到图标/关联 | 坞上热区 | 搜索后预览 | **拖图标/主窗 → 单实例传路径** |
| 落点 | 常开新窗或关联 App | 浮层动作菜单 | 仍在搜索 UI | **复用 MACOS 桌面，不另造 Overlay** |
| 根目录 | 多为文件所在夹 | 无「根」概念 | 无 | **永远以文件父目录为根** |
| 后续动作 | 取决于 App | 一键复制/上传等 | 打开/复制路径 | **预览为主；导入记事本需显式一点** |

### 必学（至少 3 条）

1. 第二进程把路径交给已运行实例，不双开  
2. 立刻能看见文件内容（预览），而不是只打开空壳目录  
3. Esc / 切走不打断其它应用（走壳层 Summon，非模态死锁）

### 明确不学 / 否决

1. 拖入即自动建记事草稿（主理人选 A）  
2. 独立 Drop Overlay 与 column_preview 双预览  
3. 拖入改全局「日常桌面根」以外的隐式策略（本次拖入会话根=父目录并 `save_root`，与「永远父目录为根」一致）

## 3.5 三个独到之处（与主理人共创 · 门禁核心）

> 草案如下，**须主理人逐条确认**后勾选。

| # | 独到主张（一句话） | 用户可感知价值 | 可测验收 | 论证结论 |
|---|--------------------|----------------|----------|----------|
| 1 | **拖入直达 MACOS 桌面，根永远=文件父目录** | 像「就在这个夹里打开 Finder」，不用再点选根 | 拖 `D:\a\b\x.png` → 根为 `D:\a\b`，选中 `x.png` 且右侧可预览 | 已确认 |
| 2 | **预览与导入记事分离：看完再一点** | 误拖不会污染记事本；主路径仍是浏览 | 拖入后无自动新记事；点「导入记事本」后草稿出现（图附件/文正文） | 已确认 |
| 3 | **图标拖入与主窗拖入同一套手势，单实例传路径** | 无论 TOA 是否已开，拖一下就进同一桌面会话 | 已开实例时再拖到图标 → 不新开进程；主窗收到路径行为与图标一致 | 已确认 |

共创纪要：

- 浏览落点 = `column_preview`，非独立 Overlay  
- 方案 A + 永远父目录为根

## 4. 技术方案（过门才写码）

| 项 | 结论 |
|----|------|
| 选定栈 / 库 | 扩展 `single_instance` IPC（`open\0path1\0path2`）；`MainShell` 路由 → `column_preview.open_paths`；工具条「导入记事本」→ `quick_notepad` API |
| 否决项 | 新侧栏模块；拖入自动建记事；第二套预览浮层 |
| 落点 | `services/single_instance.py` · `app/main.py` / `app/shell.py` · `modules/column_preview/` · 轻量桥到 notepad |
| 性能 | IPC 只传路径字符串；进页不联网；大图预览沿用桌面现有上限 |
| 品质验收 | 兑现 §3.5；Esc/切模块可退；状态栏失败提示 |

### MVP 范围

- Office / 图片 / 文本(txt 等) / 视频 / 音频：桌面预览 +「导入记事本」
- 图嵌入正文；文本进正文；Office 摘录+附件；音视频附件链接
- 文件夹 = 以该夹为根并进入  
- 跨父多文件：以**第一个**父为根，状态栏提示「其余 N 个不在当前根」  

### 非本迭代

- 注册表「打开方式」全面接管  
- 桌面内嵌音视频播放器（可系统「打开」；记事内为附件链接）
- PDF 完整内嵌预览增强（沿用桌面现能力）
