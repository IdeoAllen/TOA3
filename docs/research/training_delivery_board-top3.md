## 1. 用户场景（必填 · 主理人已确认）

| 项 | 内容 |
|----|------|
| 谁 | 教务/培训运营；TOA 免费用户可升级高级；演示含「不用 DMS、配合腾讯文档」的小团队 |
| 何时 | 开班准备 → 课中补料 → 交前自检打包；**不替代** DMS 系统化台账/核销/企微 |
| 输入 | 班级名、本机根目录、腾讯文档链接或导出花名册/排期（可粘贴） |
| 输出 | 环节进度可见；一键跳转已有业务工具且 **带上班级上下文**；本机产物可（可选）人工交 DMS |
| 失败体验 | 无根目录/无表 → 人话引导；腾讯文档未 OAuth → 降级粘贴或打开网页工作台，**不堵**主路径；未装 DMS **仍可用** |

**产品句**：DMS=专业高门槛可售；TOA=免费钩子+高级付费；腾讯文档配合轻量轨；并行不强绑。

**边界（硬）**

| 做 | 不做 |
|----|------|
| 编排壳：串已有模块 | 迷你 DMS（班级真相、核销、企微、RBAC） |
| 班级上下文本机落盘 | DMS API 硬依赖；进页同步联网探测 |
| 腾讯文档弱耦合 | 通用 Jira；第二套侧栏导航 |

**建议串链对象（已有）**

`directory_generator` → `table_card_generator` / `watermark_photo_generator` / `schedule_*` → `directory_inspector` / `deliverable_directory_check` / `enhanced_directory_inspector` → `file_packager`

## 3. 取长补短（服务亮点）

| 维度 | 飞书/Notion | 培训 SaaS | 文件夹+Excel | **我们可偷师 / 必须避开** |
|------|-------------|-----------|--------------|---------------------------|
| 核心流程 | 勾选进度 | 系统内任务 | 人肉记在表上 | 偷：进度一眼清；避：做成在线项目制 |
| 交互 | 协作强、本机弱 | 重账号 | 零学习 | 偷：点环节即办事；避：强制登录另一套 |
| 产物 | 很少出桌卡/zip | 重采集台账 | 产物在磁盘但乱 | **本机材料链是我们的场** |
| 俗套 | 「协作看板」 | 「数字化开班」 | 无产品主张 | 不抢 DMS「完善系统」词 |

### 可偷师

1. 当前卡在哪一环，不用猜  
2. 点一下就进入「能出活」的工具，而不是说明书  
3. 无网 / 无重系统也能推进材料  

### 明确不学 / 否决

1. 多角色审批、企微触达、核销（归 DMS）  
2. 远程班级真相源强制在线  
3. 再做一个「培训项目管理」通用看板

## 3.2 设计亮点挖掘（产品角度）

| 候选亮点（一句话） | 为何不落俗套 | 可感知？ | 可测？ | 入选 §3.5？ |
|--------------------|--------------|----------|--------|-------------|
| **班级上下文一次绑定，全链带根目录/名单** | 竞品要么重系统账号态，要么散装工具每次重选路径；我们钉的是「本机班级会话」 | 是 | 是 | **是 → #1** |
| **开班→交付环节可复跑，不依赖 DMS** | 不是「又一个清单 App」，而是声明轻量轨可独立成交；与高门槛 DMS 错位 | 是 | 是 | **是 → #2** |
| **腾讯文档弱耦合：链接可开，无 OAuth 粘贴仍能跑** | 不把「对接成功」当产品；对接失败降级是设计，不是抱歉 | 是 | 是 | **是 → #3** |
| 侧栏里再列一遍业务图标 | 俗套导航，无新信息 | 弱 | — | **否**（菜单导航不算亮点） |
| 「一站式培训数字化」 | 与 DMS 撞车，且空 | 弱 | — | **否** |
| 美观统一的看板卡片 | 平台主题通例 | 弱 | — | **否** |
| 完成后 show_saved | 平台铁律 | 是 | 是 | **否**（不作独到） |
| AI 自动排课/自动质检 | 未承诺栈；易空转 | 否 | 否 | **否**（本波不做） |
| 班级进度百分比大屏 | 重系统味；轻量轨不需要 KPI 墙 | 中 | 是 | **否**（易俗套、偏 DMS） |

### 俗套否决清单

| 俗套说法 | 本功能为何不用它当独到 |
|----------|------------------------|
| 「一键智能开班」 | 无可靠自动编排；吹了会翻车 |
| 「统一体验 / 高颜值看板」 | 主题与控件库通例，非本功能差异 |
| 「本地优先」 | 全产品通例 |
| 「打开所在目录 / show_saved」 | 平台铁律 |
| 「培训数字化 / 完善运营」 | DMS 的词；我们卖轻量材料链 |
| 「协作多端同步」 | 推腾讯文档本身，不在 TOA 重做协作账本 |

## 3.5 三个独到之处（与主理人共创 · 门禁核心）

> 来自 §3.2；须主理人按「不落俗套」逐条确认。

| # | 独到主张（一句话） | 用户可感知价值 | 可测验收 | 论证结论 |
|---|--------------------|----------------|----------|----------|
| 1 | **班级上下文一次绑定，全链带根目录/名单** | 换桌卡/水印/打包不用反复选路径 | 绑定后打开串链内模块，根目录（或约定 handoff）仍指向该班；换班后不串台 | 已确认 |
| 2 | **开班→交付环节本机可复跑，不依赖 DMS** | 轻量轨单独能成交；无系统也能出材料 | 断网或未配置 DMS 时，仍能从看板走完建夹→至少一环生成→打包 | 已确认 |
| 3 | **腾讯文档弱耦合：有链接可打开，无 OAuth 粘贴/导入仍能开跑** | 日常不换表；试用不被对接卡住 | 仅填 URL 可打开；无 OAuth 时粘贴花名册仍能进建夹/桌卡；不弹死阻塞 | 已确认 |
