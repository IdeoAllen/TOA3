## 1. 用户场景（必填）

| 项 | 内容 |
|----|------|
| 谁 | 培训运营 / 助教，做班级交付材料质检 |
| 何时 | 班级交付目录已齐备，交件或复盘前 |
| 输入 | 选中「班级交付材料」根目录（多级，内含照片等） |
| 输出 | **Excel**：层级路径 + 图片总数(含子目录) + 状态；**Word**：封面式大纲（目录当标题）+ 各目录下图片等比嵌入 |
| 失败体验 | 未选目录提示；无图时 Word 写明「未发现图片」；大图导出不卡死 UI（后台线程） |

**与现有模块边界（主理人裁定 · 二者都需要）**

| 模块 | 菜单位置 | 做什么 | 不做什么 |
|------|----------|--------|----------|
| **本模块**（TOA2 原「目录检查工具」） | **业务** | 交付目录 → Word 大纲贴图 + Excel 图片统计 | 不做空目录/命名启发式；不生成交付 PPT |
| `directory_inspector`（现 TOA3） | **目录** | 相对路径清单、类型统计、空目录/命名检查 | 不做 Word 贴图、不做按目录图片计数表 |
| `enhanced_directory_inspector` | **业务** | 按模板**生成**交付 PPT | 不做检查报告 |

建议菜单文案：本模块恢复 **「目录检查工具」**；现 `directory_inspector` 改名为 **「目录结构检查」**，避免同名混淆。

## 3. 取长补短矩阵

| 维度 | TreeSize | Everything | Word 相册 | **TOA 采纳** |
|------|----------|------------|-----------|--------------|
| 核心流程 | 选盘→树+大小 | 搜→列表 | 手动插图 | 选班级根目录→一键 Word+Excel |
| 交互细节 | 深度树、排序 | 极简 | 排版费时 | 跟 TOA2：日志区 + 导出按钮；完成 `show_saved` |
| 性能 | 大盘可后台 | 索引快 | 大图卡 | 扫描/写文档进线程；进页不联网 |
| 能力深度 | 通用磁盘 | 无交付语义 | 无自动大纲 | **目录=大纲层级 + 图嵌入 + 含孙目录图片计数** |
| 短板避开 | 无交付 Word | 无统计导出语义 | 人工 | 不做通用磁盘分析器 |

### 必学（至少 3 条）

1. 一键产出可交件的 Word（大纲 + 图），而不是纯路径文本  
2. Excel 按层级汇总「含子目录图片数」，一眼看出空枝/缺图  
3. 导出完成可打开所在目录（对齐 `show_saved`）

### 明确不学 / 否决

1. 不做与 `directory_inspector` 合并的「万能目录工具」  
2. 不替代「交付材料生成」PPT 贴图流水线

## 3.5 三个独到之处（与主理人共创 · 门禁核心）

| # | 独到主张（一句话） | 用户可感知价值 | 可测验收 | 论证结论 |
|---|--------------------|----------------|----------|----------|
| 1 | **目录即大纲**：Word 按文件夹层级写标题，有图才贴路径与等比缩略图 | 交件方打开 Word 就是「按目录翻相册」，不用自己建大纲 | 多级样例目录导出 docx：子目录为标题样式；图在对应节下；无图目录仍有标题 | 待论证 |
| 2 | **含子目录的图片计数表**：Excel「层级路径 / 图片总数(含子目录) / 状态」 | 一眼看出哪一层缺图、哪一层已齐 | 根下两级各放图，父行计数=子和；缺目录标「缺失」 | 待论证 |
| 3 | **与结构检查分轨**：业务「目录检查」只服务班级交付；目录域「结构检查」只管路径/命名 | 侧栏不混、培训同学仍找得到 TOA2 同名入口 | 业务侧栏有「目录检查工具」；目录侧栏有「目录结构检查」；能力互不替代 | 待论证 |

共创纪要：

- 主理人说明：TOA2 目录检查 ≠ 现 TOA3 目录检查；Excel 清单统计 + Word 大纲贴图；二者都要。

## 4. 技术方案（过门才写码）

| 项 | 结论 |
|----|------|
| 选定栈 / 库 | 移植 TOA2 `directory_checker.py` 逻辑；`python-docx` + `openpyxl` + Pillow；PySide6 `BasePage` |
| 否决项 | 不改坏现有 `directory_inspector` 路径清单能力；不与 enhanced 合并 |
| 架构落点 | `modules/deliverable_directory_check/`；菜单 `group: business`；输出 `storage_paths` / `module_output_dir` |
| 性能 | 扫描与导出进 `QThread`；禁止进页同步联网 |
| 品质验收 | 见 §3.5；导出 `show_saved`；控件库按钮/表单 |
| 如何兑现 §3.5 | Word 大纲贴图；Excel 递归计数；菜单分轨改名 |
