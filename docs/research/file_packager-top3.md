## 1. 用户场景（必填）

| 项 | 内容 |
|----|------|
| 谁 | 培训运营交班级材料；行政发项目归档包 |
| 何时 | 目录已整理完（可先经目录透视/建夹），要打成一份可传微信/邮件的 zip |
| 输入 | 选中的文件与/或文件夹；预设（通用归档 / 班级交付）；输出文件名规则 |
| 输出 | 规范命名 `.zip` 落 `module_output_dir("file_packager")`；可选同目录相对路径清单；完成 `show_saved` |
| 失败体验 | 路径过长/权限不足列出失败项；空选警告；失败不落半截静默包 |

**边界**：不做加密 zip 专家模式、不解压工具箱、不做分卷 rar；默认标准 zip。

## 3. 取长补短矩阵

| 维度 | 7-Zip | 优智 | 资源管理器 | **TOA 采纳** |
|------|-------|------|------------|--------------|
| 核心流程 | 选→压缩 | 规则批处理 | 右键即压 | **选→预览清单→命名→打包** |
| 交互 | 专家选项多 | 偏批量工具 | 零配置 | **两套业务预设 + 可剔项** |
| 性能 | 大目录稳 | 批量 | 中小目录够用 | **工作线程；进度状态栏** |
| 能力深度 | 多格式/加密 | 整理链 | 仅 zip | **只 zip；保相对结构；可附清单** |
| 短板 | 与交付业务脱节 | 独立安装 | 文件名随意 | 交付命名 + 质检清单闭环 |

### 必学

1. 保留相对目录结构进包  
2. 打包前能看见将打进去的清单  
3. 本地、可打开所在目录  

### 明确不学 / 否决

1. 7z/rar/分卷/超强加密专家面板  
2. 定时同步网盘  
3. 「智能分类整理整个磁盘」类噪音

## 4. 技术方案（过门才写码）

| 项 | 结论 |
|----|------|
| 选定栈 / 库 | Python 标准库 `zipfile`；路径用 `pathlib` |
| 否决项 | 不依赖 7z 外置二进制；不做 rar |
| 架构落点 | 新建 `modules/file_packager/`；`app.yml` 已占位；`storage.yml` 已登记；图标映射 `package` |
| 性能 | 枚举与压缩在工作线程；进页零联网 |
| 品质验收 | 二级子目录结构一致；剔空夹生效；清单相对路径正确；失败不落半截包 |
| 兑现 §3.5 | ① 两预设命名 ② 剔空夹/后缀 ③ 可选清单.txt；完成 `show_saved` |
