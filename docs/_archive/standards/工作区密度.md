# 工作区密度（正文优先）

> 与 `.cursor/rules/toa3-workspace-density.mdc` 同源。  
> 目标：侧栏点进模块后，**大部分高度给干活区**，不为说明书和装饰条买单。

## 1. 分层占位

| 层 | 谁负责 | 业务页还要不要再占 |
|----|--------|-------------------|
| 壳顶栏 | 品牌 / Chip / 设置 | 否 |
| 子模块 Tab | 办公/图片/… | 否 |
| 侧栏 | 功能模块名 | **不要**再用 `PageHeader` 重复模块名+长说明 |
| 业务页 | 任务 UI | 工具条精简、正文最大化 |

## 2. 硬规则

1. 主工作区页（记事、剪贴板、四象限、截图结果页等）**默认不设**带长 hint 的 `PageHeader`；需要时仅短标题或完全省略。  
2. 布局说明（「左大纲右正文」）→ ToolTip / 空状态一句，**不占常驻行**。  
3. `FormSection` 标题与区内 Hint **不得同义重复**。  
4. 格式/筛选类第二工具条：**按模式显隐**，默认不占位。  
5. 非常用：导入、协作表、全屏 → `MenuButton「更多」`。

| `pdf_toolkit` / `file_packager` / `batch_rename` | 待查 | |
| 其它带 `PageHeader(..., long hint)` | 待查 | 副标题超过 ~20 字优先删 |

## 4. 验收（目测）

- 1366×768 或笔记本窗口：记事正文区高度明显大于顶上工具带合计。  
- 设计态才见格式栏；源码/预览/简约不占格式行。  
- 无「左大纲 · 右正文 · …」常驻副标题。
