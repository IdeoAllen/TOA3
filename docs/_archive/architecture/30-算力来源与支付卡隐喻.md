# 30 · 算力来源与支付卡隐喻

> 产品口径：ComfyUI / Ollama / 厂商 Key / 本机生图 = **算力来源**；对用户像「绑卡 → 设默认 → 一键解绑」。  
> 平台做接入、Ready、路由；任务页尽量无感。  
> 关联：[19-AI子模块与多模态模型中枢](19-AI子模块与多模态模型中枢.md) · [20-模型库与ComfyUI式就绪列表](20-模型库与ComfyUI式就绪列表.md) · [29-扩展增长中心与模型接入及软资产](29-扩展增长中心与模型接入及软资产.md)

## 1. 隐喻对照

| 支付（用户已懂） | TOA 算力 |
|------------------|----------|
| 搜银行 → 绑定银行卡 | **绑定**算力来源（装本机 / 填 Key / 指到 Ollama·Comfy） |
| 选默认支付卡 | 每个能力一张 **默认来源**（写字 / 生图…） |
| 一键解绑 | **解绑**（清 Key / 取消默认；本机文件可保留） |
| 结账不讲银联协议 | 助手 / 媒体工坊 **不讲** Comfy、GGUF、endpoint |

**Harness 编码智能体**不进办公「算力卡包」（开发 Agent Key 独立）。

## 2. 架构（不另起账本）

```
绑定 → model_catalog profile (+ secrets)
     → model_ready_registry（能否用）
     → active_profile_id（默认卡）
     → get_client("llm" | "image_gen")
     → 大模型助手 / 媒体工坊
```

| 隐喻 | 代码 |
|------|------|
| 一张卡 | `model_catalog` 一条 profile |
| 卡种 | `tier`：simple / advanced / cloud |
| 能否用 | `ReadyStatus` |
| 默认卡 | `get_active_profile_id` / `set_active_profile_id` |
| 自动选卡 | `services/compute_source.pick_effective_profile_id` |
| 解绑 | `services/compute_source.unbind_profile` |

## 3. 能力 × 来源矩阵

| 能力 | 用户说法 | 典型来源（profile） |
|------|----------|---------------------|
| `text_llm` | 写字 | Moonshot / DeepSeek / Ollama 本机 |
| `image_gen` | 生图 | 本机生图（推荐）· ComfyUI 专业 · 云端 |

预留：`video_gen` / `audio_gen` 同一套卡包。

生图三级阶梯（doc 20）= **生图能力下的三种卡**。

## 4. 生命周期

1. **绑定** — 填 Key / 导入离线包 / 启动 Comfy·Ollama 后刷新  
2. **Ready** — 模型库显示「可用」  
3. **设默认** — 系统设置 → 算力来源（模型管理）  
4. **调用** — 任务页优先用默认；无可用默认时自动挑第一张 Ready（优先 simple）  
5. **解绑** — 云端清 Key；本机取消默认（不默认删权重文件）

## 5. 用户感知（设置）

**系统设置 → 算力来源**（界面仍用「模型管理 / 模型库」，副标题说明）

- 写字：绑定云端 Key 或本机 Ollama → 设默认  
- 生图：安装本机生图 / Comfy 指引 / 云端 Key → 设默认  

**任务页**：默认用默认卡；进阶用户可在设置换卡。文案不出现 workflow、GGUF 等（详情折叠除外）。

## 6. 非目标

- 真实支付收银、按次计费 UI（另立项）  
- 把 Harness 并入卡包  
- 第二套 YAML 账本
