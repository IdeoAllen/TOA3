# 08 · 测试与验收

## 1. 验收哲学

TOA3 的 UI 质量靠 **自动化 + 控件库人眼**，不靠 Designer 内预览。

| 层级 | 手段 |
|------|------|
| 主题/QSS | `scripts/gen_qss_from_theme.py` 可重复生成 |
| 控件尺寸/色 | `scripts/verify_gallery.py`（规划，对标 TOA2 `verify_theme_preview.py`） |
| 模块冒烟 | `scripts/smoke_modules.py`（规划） |
| 发版前 | 控件库截图 + 核心模块手工清单 |

## 2. 控件库门禁（必须通过）

打开控件库或跑验证脚本，应满足：

1. 主色贯穿：主按钮、勾选、进度条、Tab 选中、表格选中
2. 表格选中 = `row_selected` 浅底，非系统亮蓝
3. 语义条四色可辨
4. 字号四级可辨：14 / 12 / 10 / 9
5. 按钮/输入 **min-height ≥ 32px**，文字不裁切
6. 切换 `dms_green` 等主题后全页同步（壳落地后）

## 3. 验收命令（当前可用）

```powershell
# 自动门禁（发版前 / 壳改动后必跑）
python scripts/verify_all.py

# 分项
python scripts/verify_mvp.py      # 配置、路径、菜单、主题加载
python scripts/verify_gallery.py  # QSS 令牌、控件高度、控件库构建

# 人工清单
python scripts/print_acceptance_checklist.py

# 人工界面验收
python -m app.main
```

## 5. 模块级测试

- **service 层**：pytest，无 Qt 依赖
- **page 层**：`pytest-qt` 可选，测信号与模型
- 禁止测试依赖具体像素颜色（易碎），优先测令牌是否应用

## 6. 与 TOA2 回归关系

- TOA2：`scripts/audit_theme_pages.py` 仍用于封板线
- TOA3：独立验收脚本，**不**混跑 tk 与 Qt 在同一进程
