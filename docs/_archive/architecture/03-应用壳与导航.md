# 03 · 应用壳与导航

> 本章为 **规划设计**；实现随 `app/shell.py` 落地后同步更新。

## 1. 壳的职责

应用壳（Shell）是 TOA3 的固定外框，业务模块在其内部切换，**不各自实现顶栏/侧栏**。

```
┌──────────────────────────────────────────────────────────┐
│  Shell Header  品牌 · 全局操作（设置 / 关于 / 退出）        │
├────────────┬─────────────────────────────────────────────┤
│  Shell Nav │  Module Host  （当前业务模块 page）           │
│  模块菜单  │                                             │
│            │                                             │
├────────────┴─────────────────────────────────────────────┤
│  Status Bar  状态 / 版本 / 授权提示                        │
└──────────────────────────────────────────────────────────┘
```

对齐 TOA2：`main_window` 的顶栏 + 功能导航 + Notebook/宿主区 + 状态栏。

## 2. 组件划分（规划）

| 组件 | 类/文件 | QSS 对象名 |
|------|---------|------------|
| 主窗口 | `app/shell.py` → `MainShell` | `QMainWindow` |
| 顶栏 | `ui/shell/header.ui` | `#ShellHeader` |
| 导航区 | `ui/shell/nav.ui` | `#ShellNav` |
| 模块宿主 | `QStackedWidget` | `#ModuleHost` |
| 状态栏 | `QStatusBar` | 标准 |

导航按钮：`objectName=NavButton`，`:checked` 表示当前模块（见 `dms_blue.qss`）。

## 3. 模块加载机制（规划）

```python
# app/module_registry.py（规划）
MODULES = [
    {"id": "home", "title": "首页", "factory": HomePage},
    {"id": "gallery", "title": "控件库", "factory": ControlLibraryPage},
    # ...
]
```

流程：

1. 启动时读取 `config/app.yml` 的 `enabled_modules` / 授权
2. 为每个模块 `factory()` 创建实例，放入 `QStackedWidget`
3. 点击导航 → `setCurrentWidget` + 更新 Nav 选中态
4. 切换主题 → `apply_theme(app)` + 各模块 `on_theme_changed()`（可选）

**禁止**用 `QTabWidget` 当模块外壳（与 TOA2 铁律一致）；用 `QStackedWidget` 或单页替换。

## 4. 与 Designer 的配合

1. 在 Designer 中编辑 `ui/shell/main_window.ui`
2. 顶栏、侧栏、宿主区用 **布局管理器**（`QVBoxLayout` / `QHBoxLayout`），避免绝对坐标
3. 模块页 **不** 嵌入 shell.ui，由代码 `stack.addWidget(module_page)`

## 5. 生命周期

| 事件 | 动作 |
|------|------|
| `main()` | 创建 `QApplication` → `apply_theme` → 创建 `MainShell` |
| 用户换主题 | 写配置 → `gen_qss`（可选）→ `apply_theme` → 通知模块 |
| 模块 `showEvent` | 仅刷新本页数据，不重跑全局样式 |

## 6. 迁移自 TOA2 的注意点

- TOA2 `notebook` 多 Tab 隐藏原生标签 → TOA3 用导航按钮 + Stack
- TOA2 `apply_standard_to_page` 全树遍历 → TOA3 **不需要**，QSS 全局生效
- 托盘、热键、截图：迁入 `app/` 或 `services/`，与壳同级初始化
