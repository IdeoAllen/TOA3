# 29 · 扩展增长中心与模型接入及软资产

> 状态：**approved**（主理人规划落地 · 2026-08-29）  
> 关联：`18` · `19` · `20` · `25` · `28` · `28b` · `28c` · `config/feature_packs.yml`（`extension_studio`）  
> 目标：把「Harness + 用户扩展」定为 App **增长中心**；统一模型双轨心智；落地工作场景玩法；预留多 Agent 适配；远期收集优秀扩展与 Prompt/Skill 软资产社区。

---

## 0. 产品裁定

| 裁定 | 含义 |
|------|------|
| **增长中心** | 用户在沙箱内自建/进化本机 TOA，不改官方 `modules/` |
| **v1 运行时** | 仅 DeepSeek Harness；WorkBuddy / Codex / Claude Code 仅进 AgentRuntime 设计 |
| **模型双轨** | 办公 LLM/生图 = `model_catalog` + `integrations`；编码 Agent Key = DSH；**不**把 Harness 塞进 `get_client("llm")` |
| **社区** | P3 定契约与运营台审核态；近端不做交易商店前端（P2 先做本机 zip 管道） |

**口径**：成品套件（剪贴板/培训业务…）与自建能力（扩展平台）分 SKU；`extension_studio` = `user_extensions` + `harness_agent`。

---

## 1. 增长中心定位

```text
① 办公套件集成     装即集成
② 官方业务能力     培训运营等（发版维护）
③ 扩展增长中心     系统场景 / 一句话加功能 / Harness 开发 → 业务侧栏
         ↓
   岗位进化（FDB）→ 远期软资产社区（优秀扩展 · Prompt · Skill）
```

| 入口 | 用户感知 | 代码 |
|------|----------|------|
| 顶栏 **系统 → 扩展** | 增长中心：场景模板 + 生命周期 | `modules/user_extensions/` |
| 顶栏 **智能体** | 开发力（Harness） | `modules/harness_agent/` |
| 设置 **模型管理** | 办公模型 Ready | `model_registry_section` |
| 设置 **能力接入 · Harness** | 开发智能体 Key | `harness_credentials` |

Harness **不是**扩展管理入口；扩展中心 **不是**第二套智能体聊天。

## 2. 模型双轨与用户路径

### 2.1 双轨表

| 轨 | 配置 | 服务 | UI |
|----|------|------|-----|
| **办公** | `config/model_catalog.yml` · `data/user/model_catalog.yml` | `model_catalog` → `get_client("llm"|"image_gen")` | 系统设置 → 模型管理 |
| **开发 Agent** | `config/harness.yml` | `harness_credentials` → DSH `.credentials.yaml` | 能力接入 / 智能体页 |

### 2.2 小白路径

```text
第一次：系统 → 模型管理 → 填办公模型 Key → 状态 Ready
开发扩展：系统 → 扩展 → 添加/场景 →（需 Harness Key）→ 智能体开干
日常办公：大模型助手 / 截图翻译 → 选 Ready 模型
扩展内调模型：仅 get_client + plugin.toml integrations 声明
```

### 2.3 定案与否决

- 任务页只选 Ready，不堆 API 表单。
- P1：办公轨可增 Anthropic 等适配；Ollama Ready 打磨；**不**把 Claude Key 喂给 DSH。
- Harness 内模型选择仍归 DSH Web；TOA 保证 Key/Sidecar/扩展投喂链路。

## 3. AgentRuntime（多 Agent 适配层）

模块：`services/agent_runtime/`。

| 接口 | 职责 |
|------|------|
| `ensure_workspace(path, title)` | 登记工作区 |
| `open_dev_session(...)` | 新建会话并可选投喂 |
| `resume_dev_session(...)` | 回到已有会话（不新建） |
| `prompt(session_id, text)` | 投喂 |
| `navigate_focus(shell, ...)` | 壳内定位智能体页 |

- **v1 唯一实现**：`HarnessAgentRuntime` → 委托 `harness_toolkit` / Host RPC。
- `extension_lifecycle` **只依赖** AgentRuntime，不直耦 Host RPC。
- 远期：Codex / Claude Code 驱动实现同一接口；产品路径（扩展中心）不变。

**否决**：TOA 内 Cordis/dsh 插件安装器；外部 Agent 插件直接挂 TOA 侧栏（见 doc 18）。

## 4. 工作场景应用方法

扩展中心同一页、不第二套菜单：

| 玩法 | 用户动作 | 落点 |
|------|----------|------|
| 一句话加功能 | 填名称 → 添加并去开发 | `create_and_start_development` |
| 场景模板 | 选样例 → 复制为我的扩展（可再去开发） | `assets/samples/scenarios/` + `copy_scenario_as_extension` |
| 办公链投喂 | 剪贴板/截图 → 智能体快捷指令 | `harness_prompts` / feed |
| 开发完成上架 | 体检 → 业务侧栏 | `extension_guard` + `lifecycle=ready` |

场景样例（只读，可复制）：日报助手骨架、粘贴整理骨架、台卡变体骨架（≥3）。

## 5. Host Capability L1–L3（复杂场景与售卖档）

| 档 | 能力面 | 售卖暗示 |
|----|--------|----------|
| **L1** | BasePage / widgets / `module_*_dir` / show_saved | `user_extensions` |
| **L2** | 模板资源白名单、excel_export、声明 integrations | + templates / integrations |
| **L3** | job 动作注册、notify_bus、OCR/LLM | + automation |

官方深度模块（日程提醒、交付 mapping、简历 OCR）宜留官方；用户扩展做岗位变体，经 L2/L3 声明调用宿主，禁止摸私货路径。

## 6. 软资产与社区（现阶段 · 无偿流通）

详见 [29b](29b-软资产契约字段表.md)。

| 资产 | 本机 | 上架契约 |
|------|------|----------|
| 扩展包 | `data/user/extensions/<id>/` | `extension.pack`：zip + plugin.toml + 摘要 + 审计 |

**终端扩展页一站**：创造 → 上传 → 检索（信息卡片）→ 下载 → 应用。

**运营台平台控制**：

| 模块 | 能力 |
|------|------|
| 账号管理 | 列表、启用/停用（停用禁上传与下载） |
| 办公插件 | 审核、上架/下架、启用/停用、卡片字段 |
| 上下载记录 | 流水查询（不计费） |

- 前期 **无偿流通**；系统只记上传/下载流水。  
- 云 API：`/api/toa-soft-assets`、`/api/toa/customers`（toa-cloud）。  
- **不**与 DMS 强绑；交易/支付另立项。

## 7. 分期 P0–P3

| 期 | 交付 | 验收 |
|----|------|------|
| P0 | 本文档 approved；扩展中心「增长中心」口径 | 文案与文档一致 |
| P0.5 | ≥3 场景样例 + 复制为我的扩展 | 小白走出一条场景主路径 |
| P1 | AgentRuntime 抽象；模型双轨说明对齐 UI | 创建扩展链路冒烟不变 |
| P2 | zip 导出/导入 + 审计 | 另一机可导入同包 |
| **现阶段** | 无偿社区：投稿/审核/公示卡片/下载 + 运营台三模块 | 扩展页五件事 + 平台启用停用上下架 |
| 后置 | L2/L3 Host Capability；先试用再有偿打磨；交易 | — |

**本期不实现**：多 Agent 并列、软资产支付、官方业务拆成扩展、扩展个数配额。

## 8. 否决项

- 扩展同 id 覆盖官方模块
- Cordis → TOA 侧栏
- Harness Key 混进 `integrations_secrets` 破坏 DSH 路径
- P0 做交易社区前端
