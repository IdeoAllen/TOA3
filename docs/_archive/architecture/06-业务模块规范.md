# 06 · 业务模块规范

## 1. 模块结构

```
modules/<feature_id>/
  __init__.py
  page.py           # UI 逻辑：加载 .ui、绑定信号、调用 service
  page.ui           # 或 ui/modules/<feature_id>/page.ui
  service.py        # 可选：本模块业务（无 QWidget）
```

**page.py 只做**：

- 加载布局
- 连接按钮/输入事件
- 调用 `services/` 或本模块 `service.py`
- 展示结果、错误提示（用标准对话框）

**page.py 不做**：

- 颜色、字号、padding
- 复杂布局手写（应放 Designer）

## 2. 新建模块 checklist

- [ ] 在 `config/storage.yml` 登记 templates/samples
- [ ] 创建 `ui/modules/<id>/page.ui`（Designer）
- [ ] 创建 `modules/<id>/page.py`（继承 `BasePage`）
- [ ] 仅使用 `widgets/` 与控件库已登记控件
- [ ] 在 `services/menu_registry.py` → `MIGRATED_MODULES` 登记
- [ ] 菜单项已在 `config/app.yml`（通常已有）
- [ ] 跑 `python scripts/verify_all.py`
- [ ] 控件库无同类遗漏时，补 gallery 一节

## 3. 从 TOA2 迁移步骤

### 3.1 评估

| 迁移动作 | 说明 |
|----------|------|
| **保留** | `*_processor.py`、生成逻辑、模板路径、数据读写 |
| **重写** | 所有 tk/ttk UI、`page_standard` 工厂调用 |
| **对照** | TOA2 `modules/<id>/*_page.py` → TOA3 `page.py` + `.ui` |

### 3.2 推荐迁移顺序

1. 系统设置（主题切换、关于）
2. 首页（轻交互）
3. 桌卡生成
4. 目录检查 / 批量文件夹
5. 其余按业务优先级

### 3.3 逻辑迁移示例

```text
TOA2: modules/table_card_generator/table_card_generator_page.py
      + 大量 ttk 布局

TOA3: services/table_card/generator.py  ← 从 TOA2 提取纯函数/类
      modules/table_card/page.py        ← 新 UI
      ui/modules/table_card/page.ui
```

## 4. 对话框与列表

| TOA2 | TOA3（规划） |
|------|----------------|
| `BaseEditDialog` | `widgets/dialogs.py` → `EditDialog` |
| `BaseListPanel` | `widgets/list_panel.py` |
| `ask_display_name` | `widgets/dialogs.ask_text` |

列表行操作按钮：用 `RowButton`，**禁止** `width=2` 压扁可点区域。

## 5. 路径选择行

系统 `QFileDialog` **不可主题化**；可主题化的是：

- 路径 `LineEdit`
- 「浏览…」按钮（`SecondaryButton`）

封装：`widgets/inputs.PathRow`（对标 TOA2 `page_path_row`）。

## 6. 线程与长任务

- 耗时操作用 `QThread` / `QRunnable` + 信号，**不**阻塞 UI 线程
- 进度用标准 `ProgressBar` + 可选取消按钮（主按钮样式）
- 与 TOA2 线程约定对齐，避免双轨
