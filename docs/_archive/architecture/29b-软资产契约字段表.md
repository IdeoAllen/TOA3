# 29b · 软资产契约字段表（扩展包 / Prompt / Skill）

> 状态：**approved**（随 doc 29 · 现阶段社区实装）  
> 用途：运营台目录、投稿审核、终端卡片检索；**前期无偿流通**，只记上下载流水。  
> **不含**支付/交易实现。

---

## 1. 通用审核态

| `review_status` | 含义 |
|-----------------|------|
| `draft` | 作者本地 / 未投稿 |
| `submitted` | 已投稿待审 |
| `approved` | 可公示（须同时 `listed=true` 且 `enabled=true`） |
| `rejected` | 驳回（须 `reject_reason`） |
| `delisted` | 下架 |

另：`enabled`（bool）紧急冻结；`listed`（bool）是否上架公示。

云侧表：`toa_customers` · `toa_soft_assets` · `toa_soft_asset_events`（toa-cloud）。

---

## 2. `extension.pack`

本机导出：扩展根目录打 zip；根内必须含 `plugin.toml`。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `schema_version` | int | 是 | 当前 `1` |
| `asset_kind` | string | 是 | 固定 `extension.pack` |
| `plugin_id` | string | 是 | 与 plugin.toml 一致；禁止与官方 module id 冲突 |
| `name` | string | 是 | 展示名（信息卡片） |
| `version` | string | 是 | semver 或 `0.1.0` |
| `group` | string | 是 | 默认 `business` |
| `description` | string | 否 | 一句话场景（卡片简介） |
| `author` | string | 否 | 投稿人 |
| `capabilities` | string[] | 否 | 如 `["l1"]` |
| `integrations` | string[] | 否 | 如 `["ocr","llm"]` |
| `content_sha256` | string | 是 | zip 内容摘要 |
| `audit_ok` | bool | 是 | 导出前审计通过 |
| `audit_summary` | string | 否 | 审计摘要 |
| `review_status` / `listed` / `enabled` | | 云 | 见 §1 |
| `reject_reason` | string | 云 | 驳回原因 |
| `submitted_at` / `reviewed_at` | iso8601 | 云 | |

旁路：`pack.meta.json`。

## 5. API（已实装 · toa-cloud）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/toa-soft-assets?q=` | 公示目录（approved+listed+enabled） |
| POST | `/api/toa-soft-assets/submit-json` | 终端投稿（license_key + machine_id + meta + zip_base64） |
| POST | `/api/toa-soft-assets/{id}/download` | 终端下载（记流水；需启用账号） |
| GET | `/api/toa-soft-assets/admin/list` | 运营台插件列表 |
| POST | `/api/toa-soft-assets/{id}/review` | 人审：approve/reject/list/unlist/enable/disable |
| GET | `/api/toa-soft-assets/admin/events` | 上下载流水 |
| GET/POST | `/api/toa/customers` · `…/enable` · `…/disable` | 账号管理 |

人审原则：Agent **不得**自批通过/上架。
