# 13 · 白领增效工具箱与能力扩展

## 产品定位

**TOA3 = 办公室白领绝对增效必备工具箱**：把日常图片、文件/目录、办公文档、截图、番茄钟、记事本等高频能力收进一个壳，统一主题、统一授权、统一数据目录，避免「每个小事开一个网站/一个小程序」。

## 模块分层

| 层 | 职责 | 目录 |
|---|---|---|
| 壳 | 导航、热键、状态栏、授权 | `app/shell.py` |
| 控件库 | 唯一 UI 来源 | `widgets/` + 控件库页 |
| 业务模块 | 单功能一页，`BasePage` | `modules/<id>/` |
| 平台服务 | 配置、存储、菜单 | `services/` |
| 三方能力 | OCR / LLM / DMS，**业务禁止直连** | `services/integrations/` |

## 三方能力扩展（已预留）

```
业务页 → services.integrations.get_client("ocr|llm|watermark_ai")
              ↓
        config/integrations.yml（开关、端点、密钥引用）
              ↓
        具体 Client（health_check + 领域方法）
```

| 能力 | 配置键 | 典型用途 |
|---|---|---|
| `dms` | `dms.*` | 授权、台账同步 |
| `ocr` | `ocr.*` | 图片文字、扫描件 |
| `llm` | `llm.*` | 摘要、改写、模板填充 |
| `watermark_ai` | `watermark_ai.*` | AI 去水印 / 图像修复 |

新增三方能力步骤：

1. `config/integrations.yml` 登记
2. `services/integrations/<name>_client.py` 继承 `IntegrationClient`
3. `registry.py` 注册
4. 系统设置「三方能力」区展示状态
5. 业务模块只调 `get_client()`，不写 URL/密钥

## 模块迁移规范

1. 逻辑放 `*_service.py`，UI 放 `*_page.py`
2. 列表 CRUD 用 `widgets.list_edit.ListPanel` + `FormEditDialog`
3. 路径用 `services.storage_paths`
4. 登记 `menu_registry.MIGRATED_MODULES`
5. 需要授权的菜单项设 `requires_license` / `feature_id`；门禁走 `services.access_control.can_open`
6. 长任务/提醒走 `services.job_scheduler`；用户提示走 `services.notify_bus.notify`

## 架构扩展（已落地）

| 组件 | 路径 | 用途 |
|---|---|---|
| 访问控制 | `services/access_control.py` | 打开模块唯一门禁 |
| 功能包 SKU | `config/feature_packs.yml` + `services/feature_packs.py` | 授权出售单位 → 菜单展开 |
| 通知总线 | `services/notify_bus.py` | status/dialog/tray/email |
| 定时任务 | `services/job_scheduler.py` | 间隔任务落盘 + QTimer |
| 托盘 | `services/tray_service.py` | QSystemTrayIcon |
| 全局热键 | `services/hotkey_service.py` | Win32 RegisterHotKey |
| 命令面板 | `app/command_palette.py` | Ctrl+K |
| 模块隔离 | 懒加载 + `module_isolation` 约定 | 菜单变多不互相拖垮 |
| 腾讯文档 | `integrations/tencent_docs_client.py` | 占位，待 OAuth |
| 钉钉 | `integrations/dingtalk_client.py` | 占位 |

## 建议扩展功能（可分期）

- **剪贴板历史 / 片段收藏**（已 MVP：`clipboard_history`）
- **批量重命名 / 目录模板**（已 MVP：`batch_rename`）
- **PDF 合并拆分、Excel 清洗**（file 组）
- **会议计时 + 议程记事**（番茄钟 + 记事本联动）
- **大模型侧边栏**：当前页上下文一键摘要/润色（`llm` integration）
- **业务插件包（Harness 驱动）**：用户选文件夹 → 契约脚手架 → Harness 写码 → 导入挂侧栏（见 `28-Harness驱动的业务插件开发范式.md`；P0–P2）
- **钉钉/企微通知**：`integrations.yml` 预留，按需启用

## 数据目录约定

- 用户数据：`data/module/<module_id>/`
- 生成结果：`output/<module_id>/<yyyy_mm>/`
- 用户覆盖配置：`data/user/`
