# 07 · 配置与数据

## 1. 配置文件

| 文件 | 用途 |
|------|------|
| `config/app.yml` | 品牌、菜单、路径键、热键 |
| `config/app.dev.yml` / `app.release.yml` | 环境覆盖 |
| `config/themes/*.json` | UI 主题色板 |
| `config/storage.yml` | **模板/示例/模块数据布局登记** |
| `config/license.json` | 授权（gitignore） |

## 2. 存储分层（核心）

```
assets/                 随包分发（git 跟踪）· 只读参考
  templates/            官方模板 business | deliverables | generators
  samples/modules/      各模块示例输入

data/                   运行时（gitignore 内容，保留 README）
  module/<id>/          模块状态、历史 JSON
  shared/               users、knowledge_base 等
  user/templates/       用户自定义模板（优先于 assets）

output/                 生成结果（gitignore）
  <module_id>/<yyyy-mm>/  按模块 + 月份

cache/                  临时文件（gitignore）
```

**代码入口**：`services/storage_paths.py`（禁止模块手写 `../data` 路径）

| 函数 | 用途 |
|------|------|
| `resolve_template(rel)` | 用户模板 → 随包 → 项目根 |
| `resolve_legacy_template_key("resume_template")` | 兼容 app.yml 键名 |
| `module_data_dir(id)` | 模块持久化目录 |
| `module_output_dir(id)` | 本次导出目录 |
| `list_module_samples(id)` | 登记示例列表 |
| `bundled_sample(rel)` | 示例文件路径 |

启动时 `bootstrap_runtime()` → `ensure_storage_tree()` 创建目录树。

从 TOA2 拉模板/示例：`python scripts/sync_assets_from_toa2.py`

## 3. 模块迁移约定

1. 在 `config/storage.yml` `modules.<id>` 登记 `templates` / `samples`
2. 示例放 `assets/samples/modules/<id>/`
3. 模板放 `assets/templates/<category>/`
4. 运行时状态只写 `data/module/<id>/`
5. 导出只写 `module_output_dir(id)`

## 4. 路径配置（app.yml）

`paths` 桶优先于 legacy `path`；使用 `resolve_path("data_dir")` 等，支持 `{{base_dir}}`。

## 5. 授权与 DMS

见 `services/auth_service.py`（MVP stub）及 `.cursor/rules/toa3-license-dms.mdc`。
