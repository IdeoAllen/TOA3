# 25 · 体验版与付费版授权模型

> 状态：v1 裁定（2026-08）  
> **版本三分法（授权/体验/付费）与用户/订单统一规划见 `26-订单与用户统一及版本体系规划.md`**  
> 扩展增长中心 SKU：`feature_packs.yml` → `extension_studio`（`user_extensions` + `harness_agent`）；见 `29`。

## 1. 产品口径（两轨）

| 类型 | 签发入口 | 期限 | 到期后 |
|------|----------|------|--------|
| **体验版** | 运营台 → **授权管理**（或终端试用 API） | 有到期日；方案内功能在期内全开 | **全部收回**（含基础板块）；可再申请体验或购买产品方案 |
| **付费版** | 运营台 → **订单管理**履约（一订单一码） | 与订单 / 产品方案 `validity_days` 一致 | **基础板块永久可用**；方案内付费模块随到期收回 |

**术语对齐**

- 终端「体验版登录」= 单机 `local_free`（离线、无云授权码）
- 运营台签发的「体验版授权码」= 联网体验（`entitlement=trial`）
- 「正式版登录」= 激活云授权码（体验码或付费码均可）

## 2. 数据结构

### 2.1 菜单（TOA3 · 真相源）

`config/app.yml` → `menu.menu_items[]`：

```yaml
- id: clipboard_history
  requires_license: false   # 基础板块：付费用户到期后仍可用
- id: harness_agent
  requires_license: true    # 付费模块：须有效授权 + 方案 feature 命中
```

| 字段 | 含义 |
|------|------|
| `requires_license: false` | **基础板块** — **全版本永久免费**（体验/试用/付费/到期均可用） |
| `requires_license: true` | **付费模块** — 须有效授权 + 方案 feature 命中 |

云侧只读镜像：`toa-cloud/config/menu_catalog.yml`（同步脚本维护）。

### 2.2 产品方案（运营台 · 可售 SKU）

`toa_feature_packs` / 运营台「产品方案」：

| 字段 | 含义 |
|------|------|
| `pack_id` | 方案 ID（与终端 `plan_id` 同源） |
| `module_ids[]` | 本方案**额外**开放的菜单 id（不含 `local_free` 基础集） |
| `validity_days` | 默认有效天数（订单可覆盖） |
| `price_yuan` | 目录价 |

方案 = **期限 + 基础外的功能包**；`requires_license:false` 项不纳入方案售卖，**全版本永久免费**。

### 2.3 授权台账（云 · `toa_licenses`）

| 字段 | 体验版 | 付费版 |
|------|--------|--------|
| `entitlement` | `trial` | `paid` |
| `plan_id` | 可选（空 = 体验全开 / all） | 订单方案 id |
| `order_no` | 空 | 履约订单号 |
| `expire_date` | 签发天数 | 订单天数 |
| `menus_json` | 方案 feature 或 `["all"]` | 方案 feature |

签发路径：

1. **体验版** — `POST /api/toa-license`，`entitlement=trial`（默认）
2. **付费版** — 订单确认收款 → `issue_license_for_order()`，`entitlement=paid`

### 2.4 终端 `license.json`（激活后）

除既有字段外持久化：

```json
{
  "entitlement": "trial | paid",
  "plan_id": "pro_annual",
  "order_no": "TOA202608280001",
  "expire_date": "2027-08-28",
  "features": ["clipboard_history", "harness_agent"]
}
```

## 3. 门禁逻辑（`services/access_control.py`）

```
进模块 can_open(module_id)
  ├─ 壳层 / 管理员 → 允许
  ├─ requires_license=false → **永久允许**（全版本）
  ├─ 单机体验版 & 付费模块 → 拦截
  ├─ is_licensed == true → feature 命中方案
  └─ 已过期 / 未授权
       └─ requires_license=true → 拦截（试用到期 / 付费到期 / 未开通）
```

## 4. 运营台职能边界

| 页面 | 职责 |
|------|------|
| **授权管理** | 体验版发卡、补发、查看码；**不**替代订单记账 |
| **产品方案** | 定义可售 SKU（功能 + 默认天数 + 价） |
| **订单管理** | 付费版唯一商业入口；确认收款 → 一订单一授权码 |

## 5. 到期后的用户路径

**体验版到期**

1. 运营台重新「新增授权」体验版，或  
2. 终端「正式版登录」→ 设置 → 开通与续费 → 购买产品方案（生成订单码）

**付费版到期**

1. 基础板块继续可用（剪贴板、截图等 `requires_license:false`）  
2. 付费模块锁定 → 续费同方案或升级方案（新订单 → 新码激活）

## 6. 与旧数据兼容

- 无 `entitlement` 字段的历史记录：remark 含 `trial`/`试用` → `trial`；含 `订单`/`plan=` → `paid`；否则运营台手工签发视为 **trial**
- 激活响应与 `license.json` 补写 `entitlement`，无需用户重装机

## 7. 验收要点

- [ ] 运营台新增授权默认「体验版」，台账显示类型与方案  
- [ ] 订单履约码 `entitlement=paid`，终端激活后付费模块可开、基础永久  
- [ ] 体验码到期：基础模块亦不可用，文案指向续体验 / 购买  
- [ ] 付费码到期：基础模块仍可用，付费模块提示续费  
- [ ] `requires_license` 与方案 module_ids 不一致时以菜单属性 + feature 交集为准
