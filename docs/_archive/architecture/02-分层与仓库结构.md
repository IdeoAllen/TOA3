# 02 · 分层与仓库结构

## 1. 逻辑分层

```
┌─────────────────────────────────────────────────────────────┐
│  Presentation  表现层                                        │
│  modules/*/page.py  ·  ui/**/*.ui  ·  modules/gallery      │
├─────────────────────────────────────────────────────────────┤
│  Widget Library  控件库层                                   │
│  widgets/*  （Themed 封装、PathRow、ListPanel…）             │
├─────────────────────────────────────────────────────────────┤
│  Application Shell  应用壳                                  │
│  app/shell.py（规划）· 导航 · 模块宿主 · 状态栏              │
├─────────────────────────────────────────────────────────────┤
│  Theme Runtime  主题运行时                                  │
│  app/theme_loader.py  ·  resources/qss/*.qss                │
├─────────────────────────────────────────────────────────────┤
│  Theme Source  主题源                                       │
│  config/themes/*.json  ·  scripts/gen_qss_from_theme.py     │
├─────────────────────────────────────────────────────────────┤
│  Domain / Services  领域与能力（与 UI 无关）                 │
│  services/*（规划）· 从 TOA2 迁入的纯逻辑                    │
├─────────────────────────────────────────────────────────────┤
│  Infrastructure  基础设施                                   │
│  config/app.yml  ·  授权  ·  日志  ·  路径约定              │
└─────────────────────────────────────────────────────────────┘
```

**依赖规则**：上层可调用下层；下层不得 import `modules` 业务页。

## 2. 物理目录

```
TOA3/
├── app/                    # 应用层入口与壳
│   ├── main.py             # QApplication、启动控件库/主壳
│   ├── theme_loader.py     # 读 JSON/QSS、apply 到 app
│   └── shell.py            # （规划）主窗口、导航、模块加载
├── widgets/                # 标准控件库（业务唯一控件来源）
│   ├── metrics.py          # 尺寸/字号令牌
│   ├── buttons.py          # （规划）PrimaryButton…
│   ├── inputs.py           # （规划）
│   └── list_panel.py       # （规划）对标 TOA2 BaseListPanel
├── ui/                     # Qt Designer 文件（仅布局）
│   ├── shell/
│   ├── gallery/
│   └── modules/<id>/
├── modules/                # 业务功能模块
│   ├── gallery/            # 控件库（验收页）
│   │   └── control_library_page.py
│   ├── home/               # （规划）
│   ├── table_card/         # （规划）
│   └── ...

├── config/
│   ├── themes/*.json       # 主题色板（与 TOA2/DMS 同源）
│   └── app.yml             # （规划）应用配置

│   ├── qss/*.qss           # 生成物，勿手改
│   ├── icons/

├── scripts/

├── tests/                  # （规划）
├── requirements.txt
└── README.md
```

## 3. 包职责表

| 路径 | 职责 | 禁止 |
|------|------|------|
| `app/` | 进程生命周期、全局主题、壳 | 写业务规则 |
| `widgets/` | 可复用控件、属性/class 与 QSS 对齐 | 引用具体业务模块 |
| `ui/` | Designer 布局、对象名、提升类名 | 业务逻辑、网络/文件 IO |
| `modules/` | 单功能页面、信号绑定、调用 services | `setStyleSheet`、裸样式 |
| `services/` | 纯 Python 能力（解析、生成、校验） | import PySide6 Widget |
| `config/themes/` | 色板 JSON | 手写 QSS |
| `resources/qss/` | 生成皮肤 | 手改（改 JSON 再 gen） |

## 4. 模块命名约定

```
modules/<feature_id>/
  __init__.py
  page.py          # QWidget/QMainWindow 子页，加载 ui
  page.ui          # 或放在 ui/modules/<feature_id>/page.ui
  service.py       # 可选：本模块专用逻辑
```

- `feature_id` 与 TOA2 `modules/` 目录名尽量一致，便于迁移对照
- 菜单显示名中文，代码标识英文 snake_case

## 5. 与 TOA2 目录对照

| TOA2 | TOA3 |
|------|------|
| `main_window.py` | `app/shell.py` + `ui/shell/main_window.ui` |
| `common/page_standard.py` | `widgets/` + `docs/standards/控件库规范.md` |
| `common/themed_widgets.py` | `widgets/*` |
| `common/theme_manager.py` | `app/theme_loader.py` + QSS |
| `config/themes/*.json` | 同源，`scripts/sync_themes_from_toa2.py` |
| `modules/*_page.py` | `modules/*/page.py` + `.ui` |
