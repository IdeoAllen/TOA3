# 09 · 打包与发布

> 本章为 **规划**；`packaging/` 目录待壳稳定后创建。

## 1. 目标

- 单文件或目录发行版 EXE（Windows 优先）
- 体积可控（Qt 运行时约 +40~80MB vs tk）
- 与 TOA2 安装包可并存，版本号 **3.x** 区分

## 2. 工具链（规划）

| 工具 | 用途 |
|------|------|
| PyInstaller | 主打包 |
| Inno Setup / 现有 `toa_setup.iss` 改版 | MSI/安装向导 |
| `packaging/TOA3.spec` | 数据文件、隐藏导入 |

## 3. 必须打入的资源

```
config/themes/*.json
resources/qss/*.qss
resources/icons/*
templates/          # 若模块依赖
config/app.release.yml
```

**不**打包：`.venv`、`data/` 用户数据、`license.json`（首次运行生成）。

## 4. PySide6 打包注意

- `hiddenimports` 包含 `PySide6.QtUiTools` 等
- 平台插件：`platforms/qwindows.dll` 等由 PyInstaller hook 处理，需实机验证
- 在 **clean VM** 测安装包，避免开发机 Qt 路径泄漏

## 5. 版本策略

| 线 | 版本 | 说明 |
|----|------|------|
| TOA2 | 2.2.x | 封板，tag `toa2-frozen-*` |
| TOA3 | 3.0.0+ | 新安装包名称可含 `TOA3` 或继续 `TOA` 由产品定 |

`config/app.yml` 中 `brand.app_version` 与安装包一致。

## 6. 发布流程（对齐 DMS）

- 业务发布仍走 DMS 流程（见 TOA2 `.cursor/rules`）
- TOA3 独立构建脚本，**不**覆盖 TOA2 生产路径除非产品切换默认安装包

## 7. 回滚

- 用户可继续使用 TOA2 安装包
- TOA3 公测期建议并行发行，数据目录共用需注意兼容性
