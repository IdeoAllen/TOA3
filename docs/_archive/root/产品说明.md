## 1. 三十秒读懂

| 项 | 说明 |
|----|------|
| **对外名称** | 运营宝 / TOA（桌面办公套件） |
| **技术线称谓** | TOA3（相对封板的 TOA2 桌面版而言的现行主产品） |
| **一句话** | 办公室人员安装本软件，即等于集成剪贴板、截图、记事、目录、文件、桌面浏览与培训业务等常用效率工具——一站替代多软件来回切换。 |
| **使命** | 打开就能用 · 用完不想换 |
| **愿景主张** | 少点一下，多干一件事——把截图、记事、剪贴板与目录文件，收进同一处顺手工具。 |
| **目标** | 成为办公室工作人员最爱、最方便、最离不开的桌面办公软件。 |
| **给谁用** | 培训运营、教务、行政与通用白领 |

**能力定位（硬标准）**：每个能力都对标市面同类工具；我们只是集成到一处，免去到处找——**绝对不能比同类差，否则就是败笔。**

## 2. 产品意义与价值（供专家分析）

本章按「问题 → 主张 → 证据 → 检验」组织，便于外请专家批注与二次论证；**不是营销吹捧稿**。

### 2.1 要解决的问题

办公室日常往往被「散装工具」拆碎：

| 成本 | 表现 |
|------|------|
| **切换成本** | 截图一个软件、剪贴板一个、建文件夹又一套脚本或手工 |
| **学习成本** | 每款工具交互、快捷键、主题各异 |
| **结果分散** | 产出散落各处，复盘与交付难追溯 |
| **垂直断点** | 培训运营还需桌卡、日程、班级材料检核——通用效率套件通常不管 |

用户要的不是「又多一个 App」，而是：**少装几个、少切几下、结果还在本机找得到。**

### 2.2 产品主张

1. **一站集成**：安装 = 工具箱到位，高频办公动作不必再到处找独立软件。  
2. **单项不输头部主路径**：集成不是「凑合能用」；截图、剪贴板等须对标 Snipaste / Ditto 一类的主路径体验。  
3. **键位跟手、步骤尽量少**：全局热键少而精；覆盖层做完或 Esc 即退，默认不打断其它应用。  
4. **本地优先、可离线**：核心办事不依赖云端在线；结果落在本机，可追溯。  
5. **垂直加分而非唯一叙事**：气质是一站式办公效率；培训业务是加分能力。

### 2.3 价值主张三角

```text
          效率
       （少点一下）
            /\
           /  \
          /    \
   体验 -------- 可控
（统一专业）  （本地·可离线·可追溯）
```

| 角 | 用户可感知价值 | 产品侧兑现方式（摘要） |
|----|----------------|------------------------|
| **效率** | 同一工作流少切窗、少找入口 | 顶栏子模块 + 侧栏功能 + 热键/托盘/覆盖层双轨 |
| **体验** | 看起来像一套正式软件，而不是插件拼盘 | 全局主题与控件规范；单模块单主任务 |
| **可控** | 数据在自己电脑；断网也能办日常事 | 本机数据区；密钥本机；授权不强绑外部业务系统 |

### 2.4 差异化证据（用户感知版）

我们不用「功能更多」证明自己，而用可感知差异：

| 证据类型 | 含义 | 用户怎么感受 |
|----------|------|--------------|
| **对标头部** | 每个能力开工前对照同类 Top3 | 主路径跟独立王牌软件一样顺手 |
| **三独到处** | 每个能力承诺恰好 3 条可感知、可测的独到之处 | 不用看说明书也能感到「和竞品不一样」 |
| **验收诚实** | 「有页面」≠「做完」；有缺口就不标完成 | 绿灯代表愿意每天用，而不是菜单堆满 |

> 对专家：差异化门禁与研报见 `docs/research/*-top3.md`；本文不展开开发流程。

### 2.5 垂直加分：培训运营链

相对「纯白领效率合集」，TOA 多一段培训场景闭环（排课 → 材料 → 检核 → 交付），例如：桌卡生成、班级日程提醒、水印照片、目录透视与交付报告、助教简历与照片提取等。

- **对通用白领**：可当办公套件用，不必碰业务区。  
- **对培训团队**：同一壳内完成高频交付动作，减少 Excel + 手工拼凑。

### 2.6 明确不做（边界即价值）

宁少勿滥。当前口径下，本产品**不把精力堆在**：

- 为菜单好看而堆占位功能  
- 用番茄钟等低频能力挤占「每天真正在用」的主线  
- 本波不做的大而全文件工场（如 Office 互转、查重清理、Excel 清洗等——有强痛再评估）  
- 把培训交付做成通用项目管理（非 Jira 替代品）

**少做几个、每个做强**，本身就是定位声明。

### 2.7 价值检验题（给专家 / 主理人）

请用下面问题验收「意义是否成立」，而不是听功能清单：

1. 装完并常用一周后，是否**愿意卸载**独立剪贴板 / 截图类软件？  
2. 截图、剪贴板、记事的**主路径**，是否感觉不输 Snipaste、Ditto 一类？  
3. 培训交付场景（桌卡、材料、检核）是否比「Excel + 手工」明显更快、更少出错？  
4. 热键/覆盖层是否**默认不打断**其它应用，且 Esc/完成能立刻回到原上下文？  
5. 断网或弱网时，日常高频工具是否仍能办事？

任一题长期答「否」，则对应主张尚未兑现——应优先补强，而不是扩菜单。

## 3. 怎么用（用户心智）

### 3.1 三级结构

```mermaid
flowchart LR
  subgraph L1 [一级_顶栏子模块]
    Home[首页]
    Office[办公]
    Image[图片]
    Files[文件]
    Engines[引擎]
    Business[业务]
    System[系统]
  end
  subgraph L2 [二级_侧栏功能模块]
    Mods[当前子模块下的工具列表]
  end
  subgraph L3 [三级_任务页]
    Page[具体办事页面]
  end
  L1 --> L2 --> L3
```

| 层级 | 你怎么理解 | 在界面哪里 |
|------|------------|------------|
| **一级 · 子模块** | 「我现在进哪个工作区」 | 顶栏 Tab：首页 / 办公 / 图片 / 文件 / 引擎 / 业务 / 系统 |
| **二级 · 功能模块** | 「这个工作区里用哪个工具」 | 左侧栏列表 |
| **三级 · 任务页** | 「办这一件事」 | 中间主内容区 |

切换顶栏子模块时，侧栏会换成该工作区下的工具列表。

### 3.2 不必打开主窗也能办事

高频动作支持「系统介入」：

| 方式 | 典型用途 |
|------|----------|
| **全局热键** | 截图、剪贴板快贴、快速记事等（可在设置中关闭或改键） |
| **托盘** | 主窗收起后仍可唤起 |
| **覆盖层** | 全屏截图标注、快贴面板；做完或按 Esc 回到原工作 |
| **命令面板** | `Ctrl+K` 按关键字直达功能 |

设计原则：**默认不打断别人的工作；一次一事；跟手键位少而精。**

### 3.3 结果在哪里

生成、导出、历史等内容默认落在本机应用数据区与输出目录（界面上常提供「打开所在目录」）。  
**本地可找、可复盘**是产品承诺的一部分。

### 3.4 扩展

「系统 → 扩展」可挂接本机个性化能力（含网页扩展等）。扩展可移除，不应拖垮官方主功能。高级引擎（如编码智能体、ComfyUI 等）在「引擎」或设置中的模型相关入口配置。

## 4. 能力地图

下列为**产品能力地图**。状态口径：

| 标注 | 含义 |
|------|------|
| **可用** | 主路径已对齐或已点验，日常可依赖 |
| **打磨中** | 能用，但对照头部仍有缺口，正在做强 |
| **规划中** | 清单已有方向，产品尚未稳定交付或仍缺入口 |

> 侧栏是否显示某项，还受授权方案与个人菜单配置影响；**以软件内为准**。

### 4.1 当前主推：日常高频（个人八件套）

这是产品「每天离不开」的锚点；未达标前，其它扩展优先级靠后。

| 能力 | 解决什么 | 状态（诚实） |
|------|----------|--------------|
| 截图工具 | 区域/全屏捕获、标注、落剪贴板或文件 | 打磨中（对标 Snipaste 级体验） |
| 剪贴板历史 | 文本与图片历史、搜索、热键快贴 | 打磨中 |
| 快速记事 | 会中速记、草稿；可与剪贴板互拷 | 打磨中 |
| 四象限任务 | 重要×紧急个人看板 | 打磨中 / 待点验巩固 |
| 去水印 | 框选/涂抹去除角标等水印 | 打磨中 |
| 批量建文件夹 | 粘贴名单 → 一次建夹 | **可用**（已点验） |
| 截图翻译 | 框选屏幕 → 识字 → 译文 | 规划中（优先挂在截图工具上，避免空菜单） |
| （加水印） | 日常通用加水印 | 侧栏默认隐藏；培训「班级水印照片」走业务能力 |

### 4.2 七大子模块一览

#### 首页

- **解决什么**：一眼进高频工具；桌面式浏览本机目录。  
- **代表能力**：首页总览、桌面浏览（列式预览）。  
- **典型场景**：早上打开软件，点一下进记事/截图；或像资源管理器增强一样浏览交付目录。

#### 办公

- **解决什么**：白领一天里最高频的「复制粘贴、截图、记一笔、润色、打开网页工作台」。  
- **代表能力**：剪贴板历史、截图、记事、四象限任务、大模型助手、网页工作区等。  
- **典型场景**：会议中 Alt 系热键截图发反馈；改文案时翻剪贴板历史；记事草稿一键拷走。

#### 图片

- **解决什么**：图片处理与轻量媒体能力，不必另开修图全家桶。  
- **代表能力**：去水印、转扫描件、图转文件、照片提取、媒体工坊相关能力等。  
- **典型场景**：合同扫描感 PDF、微信发图压缩、班级照片批处理（部分与业务交叉）。

#### 文件

- **解决什么**：建夹、透视目录、重命名、PDF、打包归档、文档合成。  
- **代表能力**：批量建夹（可用）；PDF 合并/拆分/抽页、打包归档、批量重命名（打磨中，以软件内可见项为准）。  
- **典型场景**：开班前粘贴名单建目录树；交材料前规范 zip；课件 PDF 拆合。

#### 引擎

- **解决什么**：把重量级开源能力嵌进同一壳，减少「再装一套后台」。  
- **代表能力**：编码智能体（Harness，主路径已可用）、Draw.io、OpenPencil、ComfyUI 等宿主。  
- **典型场景**：在壳内指挥智能体改业务扩展；画流程图；本地生图工作流。

#### 业务（培训运营）

- **解决什么**：培训交付链路上的表格、模板与检核，减少手工拼凑。  
- **代表能力（多数主路径可用）**：桌卡生成、助教简历、扣分备注整理、排程格式转换、水印照片、照片提取、目录透视、交付材料/报告、日程提醒等。  
- **典型场景**：学员名单 → 台卡 PPT；班级目录规则加水印；交付前目录质检出报告。

#### 系统

- **解决什么**：主题、热键、授权、菜单可见性、扩展与诊断。  
- **代表能力**：系统设置、控件库（研发/验收对照）、用户扩展、关于与版本信息。  
- **典型场景**：换主题、改热键、激活授权、导入个性化扩展。

### 4.3 办公增强（八件套之外）

| 能力 | 说明 | 状态 |
|------|------|------|
| 图片转文字（OCR） | 识字底座；也支撑截图翻译 | 打磨中 |
| 大模型助手 | 润色、摘要等（需配置兼容接口） | 打磨中 |
| 图转文件 / 转扫描件 | 办公增强 | 打磨中 |
| 番茄钟 | 非最高频；可隐藏 | 降级 / 非主推 |

## 5. 授权与版本（用户口径）

TOA 桌面授权与 DMS（交付管理系统）是**两套产品**；日常使用**不强制** DMS 在线才能激活主路径。

| 概念 | 用户怎么理解 |
|------|----------------|
| **基础板块** | 标记为常驻开放的能力；付费到期后仍可继续用这些基础能力 |
| **方案内付费能力** | 随购买的产品方案开放；须有效授权，到期后收回方案内模块 |
| **体验** | 有期限的试用；到期后体验期内开放的能力会收回，可再申请或购买 |
| **付费** | 按订单/方案期限；到期后基础板块保留，方案内付费模块收回 |

具体哪些菜单属于基础或付费，以软件内授权状态与方案说明为准。运营与发码在 TOA 运营台侧完成。

## 6. 我们对用户的承诺

把内部工程原则改写成可感知承诺：

1. **看起来是一套软件**：风格统一、专业，而不是各页各色。  
2. **一页办一件主事**：进功能先看到主路径；次要项进设置或次要入口。  
3. **少切换、跟手键**：高频动作热键可达；覆盖层可退。  
4. **本地优先**：日常办事尽量可离线；结果在本机可找。  
5. **完成有交代**：生成/导出完成后有明确完成提示，并可打开所在目录。  
6. **宁少勿滥**：宁可少几个功能，也不用半成品堆满侧栏。  
7. **单项要对得起独立软件**：集成不能成为「比同类差」的借口。

## 附录：给专家的一页摘要

**产品是什么**：Windows 桌面办公套件（运营宝 / TOA），一站集成高频效率工具，并叠加培训运营垂直能力。  

**不是什么**：不是功能导航站；不是「什么都有一点」的百宝箱；不是必须绑定 DMS 才能用的插件。  

**核心赌注**：用户装完后，愿意用这一处替代多个独立小工具；培训团队在同一壳内完成交付链关键步骤。  

**成败度量**：见 §2.7 五道检验题；主观「愿不愿意每天打开」优先于菜单条目数量。
