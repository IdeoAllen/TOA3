# TOA3 单机版发布

> 发行配置：`config/app.release.yml` → `edition: standalone`  
> 功能清单：`config/feature_packs.yml` → `local_free`

## 单机版包含（local_free）

| 模块 | 说明 |
|------|------|
| 首页 | 入口 |
| 快速记事 | 本地草稿 |
| 番茄钟 | 专注计时 |
| 截图工具 | 区域/全屏 |
| 剪贴板历史 | 文本回写 |
| 四象限任务 | 本地看板 |
| 系统设置 / 任务 / 通知 | 壳层 |

完整培训业务、图片专业包等需 **授权码登录**（联网激活）。

## 用户路径

1. 安装 `TOA3-Setup-x.y.z.exe`（Portal `/downloads/`）
2. 首次启动 → **单机体验**（免码、离线）
3. 升级完整版 → **授权码登录**（TOA 运营台发卡）

## 打包

```powershell
cd TOA3
$env:TOA_ENV = "release"
python packaging/build_windows.py --msi
```

产物：`dist/TOA3-v3.0.0-win64/TOA3-Setup-v3.0.0.exe`

## 云服务（可选）
