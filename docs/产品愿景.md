# 产品愿景与目标（公示文案）

> 数据源：`config/product.yml` → `services/product_vision.py`  
> 系统公示：**首页**与**顶栏「关于」**共用 `vision_display_rows()`（使命 / 愿景 / 目标 / 定位四行同源）  
> Agent 交接：[`docs/handoff/HANDOFF_INDEX.md`](./handoff/HANDOFF_INDEX.md) §1

---

## 使命（不是口号）

**办公极简伴侣 · 少点一下，多干一件事**

> 对外首句语义为**使命**：我们承诺做成怎样的产品，而不是营销口号。

## 愿景

让办公人员感到极致简便——打开就能用，用完不想换别的软件。

## 目标

成为办公室工作人员最爱、最方便、最离不开的桌面办公软件。

## 能力定位（硬标准）

每个能力都对标市面同类工具；我们只是集成到一处，免去到处找——**绝对不能比同类差，否则就是败笔。**

- 市面上每个功能都能找到对应工具软件；TOA 做一站集成与统一体验  
- 单项能力须经 Top3 + 三独到处门禁，验收不低于品类头部  

## 命名

正式俏皮名稍后共创；现阶段以「运营宝 / TOA」示人，先把「每天离不开」的体验做实。

## 承诺

- 高频刚需做强；每项对标品类头部，宁少勿滥  
- 同类能力一站集成，少「到处找软件」  
- 键位跟手、步骤尽量少  
- 本地优先、可离线，结果在本机可追溯  
- 截图、记事、剪贴板等日常动作一站直达  

## 改文案

只改 `config/product.yml` 的 `vision:` 段，重启后首页与关于弹窗同步更新。
