## 新增控件流程

1. `widgets/` 实现 + QSS 选择器写入 `scripts/gen_qss_from_theme.py`
2. `modules/gallery/control_library_page.py` 增加展示
3. 更新本表
4. 业务模块方可使用

## 禁止

- 业务模块直接 `QPushButton` 当主按钮（须 `PrimaryButton` 或 class=primary）
- `setStyleSheet` 单控件覆写
- 未在控件库登记的自定义控件（除非注释「控件库例外：…」）
- 新建弹窗绕过 `BaseDialog` / 写死色板（账号信息、关于等系统窗同理）

## 图标清晰度（硬门禁）

所有 UI 图标**禁止模糊、锯齿、发虚**。实现与验收统一走 `services/icon_registry.py`。

### 菜单 / 侧栏图标

- 每个 `menu_items[].id` 对应独立语义图标（`config/app.yml` 的 `icon` 优先等于模块 id）
- SVG 统一 24×24、`stroke-width: 1.8`、round 线帽；渲染时再经 `_normalize_ui_svg`
- 新增模块：补 `resources/icons/svg/<name>_svg.svg`，在 `icon_registry._ALIAS` 登记，跑 `scripts/gen_menu_icons.py` 可批量对齐线宽
- 禁止多个模块共用同一个「文件/图片」占位图标（辨识度要求）

| 要求 | 说明 |
|------|------|
| 矢量优先 | 侧栏 / 顶栏 / 卡片用 SVG；禁止用小 PNG 硬放大 |
| HiDPI 光栅化 | 按**物理像素**绘制 SVG，再 `setDevicePixelRatio`；禁止只画 1× 再拉伸 |
| 取图方式 | 卡片/标签用 `icon_pixmap(...)`；勿对 `QIcon.pixmap(逻辑宽高)` 结果再缩放 |
| 抗锯齿 | `QPainter` 须开 `Antialiasing` + `SmoothPixmapTransform` |
| 多档 DPR | `QIcon` 至少登记 1 / 1.25 / 1.5 / 2 / 3 与当前屏档 |
| 截图工具栏 | 自绘 glyph 须 HiDPI；OCR≠文字≠翻译（`ocr` / `text` / `translate` 分图标） |
| ToolTip | 主题须生成 `QToolTip`（`tooltip_bg`/`tooltip_fg`）；禁止依赖 `*` 继承色 |
| 禁止 | 位图图标无 DPR；`setPixmap` 后再 `scaled` 放大；低清 ICO 作唯一来源；OCR/翻译复用「A」图标 |

自检：在 100% / 125% / 150% / 200% 缩放下，侧栏与首页卡片边缘应锐利。详见验收规则 `toa3-feature-acceptance.mdc`。

## 页面与弹窗

- 业务页：`BasePage` + `apply_standard_page_layout()`，边距/间距跟 `config/ui_spec.yml`
- 弹窗：`BaseDialog`（`ThemedDialog`），`dialog_kind` ∈ small/medium/large/login…
- 顶栏「账号」「关于」：`UserProfileDialog` / `AboutDialog`，不进侧栏堆栈
