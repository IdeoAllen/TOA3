# 快捷键分层规范（TOA3）

目标：**方便，但不抢系统习惯、不做成第二套操作系统。**

## 三层（由外到内）

| 层 | 何时生效 | 键型约定 | 示例 |
|----|----------|----------|------|
| **G 全局** | 托盘隐藏也可用（`RegisterHotKey`） | **必须**带 Alt/Ctrl（禁止裸字母） | `Alt+A` 截图、`Alt+O` OCR |
| **A 应用** | 主窗口在前台 | 优先 Ctrl/Alt；与常见软件冲突的改默认 | `Ctrl+H` 首页、`Ctrl+Q` 退出、`Ctrl+K` 命令面板 |
| **P 页内** | 仅当前模块，且焦点不在输入框 | 允许单字母；模块卸载即失效 | 首页 `K`/`I`；截图标注 `1`/`2`/`3` 线宽 |

冲突裁决：**页内 > 应用 > 全局**（同键时以更内层为准）；输入框内页内字母键让给打字。

## 默认不碰的系统习惯

- `Ctrl+C/V/X/Z/A`、`Alt+F4`、`Win+…`、输入法切换 — 不占用  
- 全局不用裸 `A–Z` / `0–9`（避免打字、游戏、其它软件误触）  
- `Ctrl+K` 留给**命令面板**（对标 VS Code / 现代桌面），不用裸 `K` 做全局  

## 首页字母（页内）

| 键 | 作用 |
|----|------|
| `K` | 跳到「办公增效」分组首个可见工具 |
| `I` | 跳到「图片处理」分组首个可见工具 |

（仅在首页且未聚焦输入框时生效。）

## 剪贴板速贴面板（弹层内）

| 键 | 作用 |
|----|------|
| **全局 `Alt+Shift+C`** | 唤起速贴面板（托盘隐藏也可用；对标 Win+V） |
| `1`–`9` | 粘贴对应候选项到**刚才的窗口**（短语优先，再补历史） |
| `↑` `↓` / Enter | 选中后粘贴 |
| Esc | 关闭 |

配置：`hotkeys.open_clipboard`（默认 `Alt+Shift+C`）。

## 截图标注（页内 / 浮层）

| 键 | 作用 |
|----|------|
| `1` / `2` / `3` | **全部**标注工具的细/中/粗（线宽或文字字号）；打字中用 `Ctrl+1/2/3` |
| `P` `R` `A`… | 工具切换（已有） |
| `Esc` | 取消 |

## 默认全局 / 应用键位一览（自检）

| 键 | 层 | 作用 | 备注 |
|----|----|------|------|
| `Alt+A` | G | **区域截图**（立刻框选） | 与 `screenshot_tool` 展示同键；全局必须跑捕获，禁止改成仅打开模块页 |
| `Alt+Shift+A` | G | 全屏截图 | 配置键名 `screenshot_region` 易误解，语义是全屏 |
| `Alt+O` | G | OCR 框选直出 | 与关于 `Alt+Shift+O` 不冲突 |
| `Alt+Shift+C` | G | 剪贴板速贴面板 | 对标 Win+V |
| `Alt+N` / `Alt+P` | G | 记事 / 番茄 | 唤起模块 |
| `Alt+S` | A | 系统设置 | 仅前台 |
| `Alt+Shift+O` | A | 关于 | 仅前台 |
| `Ctrl+H` | A | 首页 | **禁止** RegisterHotKey，避免抢走浏览器历史 |
| `Ctrl+K` | A | 命令面板 | 硬编码 |
| `Ctrl+Q` / `Ctrl+Shift+R` | A | 退出 / 重启 | |
| `F11` | A | 沉浸全屏 | Esc 退出沉浸 |
| `K` / `I` | P | 首页跳办公 / 图片 | 仅首页、非输入框 |
| `←` `→` / `↑` `↓` | P | 顶栏子模块 / 侧栏模块 | 输入框与列表内不抢 |

### 页内同键（按模块隔离，不算自冲突）

| 键 | 模块 | 作用 |
|----|------|------|
| `Ctrl+N` | 记事 / 四象限 | 各页新建 |
| `Ctrl+Shift+V` / `C` | 记事 / 扣分整理 | 粘贴整理 / 复制；进页启用 |
| `Ctrl+[` `]` · `Alt+←` `→` | 记事大纲 | 升级/降级；离开页关闭 |
| `1`–`9` | 速贴面板 | 粘贴槽；与标注 `1`–`3` 线宽不同浮层 |

### 已知无效 / 勿用

- `toggle_window: Double+Ctrl` — `RegisterHotKey` 与 `QKeySequence` 均无法解析，等于未绑定  
- 用户在 `module_shortcuts` 里给两个模块配同一全局键 → 后写丢弃；设置页应提示（待增强）

## 配置入口

- 文件：`config/app.yml` → `hotkeys:`（开发覆盖 `app.dev.yml`）  
- UI：系统设置 → 快捷键  
- 改全局键后点保存，会重新 `RegisterHotKey`；冲突会提示「可能被占用」

## 新增热键清单（实现时）

1. 先定层级（G/A/P）  
2. 查本表与 `hotkeys` 是否撞车  
3. 能页内解决的不要升全局  
4. 设置页文案写清「托盘时是否仍可用」  
5. 截图键优先于「打开 screenshot_tool」；`home` 不得进全局表  

过度设计否决：为每个菜单项分配全局键；可配置的「键位方案市场」；无修饰键的全局字母墙。
