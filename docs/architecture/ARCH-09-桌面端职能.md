# ARCH-09 · 桌面端职能规划：开源收录 · Host · 办公传送门

> 状态：**approved（主理人裁定 · 2026-09-07）**  
> 关联：[18-引擎与Harness](ARCH-05-引擎与Harness.md) · [31-主子窗隔离](ARCH-08-主子窗隔离.md) · 会话「网页干重活 / 不默认内嵌 Agent」  
> 上一稿曾强调「算力与费用中枢」——**费用管理本期明确不做**（见 §6）。

## 0. 一句话定位（已裁定）

| 面 | 职责 | 用户感知 |
|----|------|----------|
| **浏览器** | 实际业务与重活（Agent 会话、Comfy 画布、复杂 Web 工具） | 「一件打开浏览器去完成」 |
| **TOA 桌面** | **开源收录** + **引擎生命周期 Host** + **办公传送门** | 「装得上、卸得掉、坏了能修、跑着看得见」 |

**引擎生命周期六件套**（穿成一条体验，专降技术门槛）：

```text
一键安装 → 启停 → 监控日志 → 一键修复 → 版本备份 → 一键卸载
         ↘              「在浏览器打开」干重活              ↙
```

**TOA 作为传送门**：文件、剪贴板、任务、记事本（及截图等日活）→ 热键/托盘/模块内一键投喂到已启动的浏览器会话或本地路径。

**否决**

- 在桌面用 Qt **重做** Harness / Comfy 全套业务 UI  
- 默认套件内嵌；外开须用户自点；能力不及处提示「浏览器打开效果更佳」  
- 本期做 **费用 / 预算 / 用量账单** 中枢  
- 把各云厂商控制台搬进 TOA  
- 生命周期按钮散落多页、术语不一致（用户要「一件事一个钮」）

## 1. 主理人原话对齐

| 主张 | 产品含义 |
|------|----------|
| 更适合做好的开源地址收录 | 引擎/工具目录：可信仓库 URL、说明、版本钉扎、官方文档链 |
| 一键安装 / 卸载 / 修复 | 生命周期完整，失败可退回，不留半残目录 |
| 启停 + 监控日志 | 状态一眼清；日志可打开、可复制、不吓人 |
| 版本备份 | 升级前可回滚；坏了能回到上一可用版 |
| TOA = 文件·剪贴板·任务·记事本传送门 | Wave★ 办公套件做强；「送到…」投喂链 |
| 实际业务一件打开浏览器完成 | 主 CTA =「在浏览器打开」；内嵌仅可选或不做默认 |
| 费用管理先不做 | 不排期 usage ledger / 账单页 / 预算告警 |
| **穿成一条、降门槛** | 六件套同一套控件与文案范式；小白不读终端也能管引擎 |

## 2. 桌面 vs 浏览器：分工矩阵

| 能力域 | 桌面（TOA） | 浏览器 |
|--------|-------------|--------|
| 剪贴板 / 截图 / 记事 / 任务 | **传送门主力** | 接收投喂（可选） |
| 文件 / PDF / 建夹 / 打包 | **传送门主力** | — |
| 开源工具收录与目录 | **主力** | 打开官网 / GitHub |
| 一键安装与环境自检 | **主力** | — |
| 进程/端口启停与健康 | **主力** | — |
| 编码 Agent / Comfy 编排 | Host + 投喂 | **业务主力** |
| 大模型润色等轻能力 | 可保留简单路径 | 复杂长会话仍可浏览器 |
| 费用 / 多平台账单 | **本期不做** | 用户自行看厂商控制台 |

```text
收录目录 → 一键安装 → 启停绿灯 →「浏览器打开」干重活
     ↑                                      ↓
  剪贴板 / 记事 / 任务 / 文件  ──投喂──→  浏览器会话 / 本地目录
```

## 3. 桌面功能规划（按优先级）

### 3.1 P0 · 开源收录目录（Catalog）

| 功能 | 说明 | 验收 |
|------|------|------|
| 条目卡 | 名称、一句话、官方/仓库 URL、许可提示、推荐版本 | 列表可浏览、可搜索 |
| 可信来源 | 仅配置/运营登记的条目（本机 yaml 或随包清单） | 用户不能随意注入未知脚本为「官方」 |
| 外链 | 「打开仓库」「打开文档」走系统浏览器 | 不嵌 GitHub 页 |

**落点建议**：`engines` 子模块下「引擎目录」或现有引擎页顶部「收录」区；配置可挂 `config/` 或 `integrations` 旁清单（实现时再定，须过 Top3 若新模块）。

### 3.2 P0 · 引擎生命周期六件套（Host 核心体验）

> **产品主张**：把「装 / 卸 / 修 / 启停 / 日志 / 备份」穿成同一条主路径，  
> 比再嵌一个网页控制台更能降低门槛——用户永远知道「下一步点哪个钮」。

| # | 能力 | 用户一句话 | 体验铁律 | 验收 |
|---|------|------------|----------|------|
| 1 | **一键安装** | 「装上就能用」 | ≤3 步；缺前置（如 Node）给人话 +「去安装」；落盘固定独立目录 | 小白不读文档装通 |
| 2 | **一键卸载** | 「不要了干净走人」 | 停进程 → 清目录 → 清端口登记；可选保留用户数据 | 卸后侧栏/目录不再半残 |
| 3 | **修一下** | 「坏了再点 · 事故底牌」 | Host **自读启动日志**；清锁/组件/插件；入口在「环境维护」；失败态临时露工具栏；**≠** 网吧整机还原 | 失败不静默；日常傻瓜路径不依赖它 |
| 4 | **启停** | 「开/关就这两个钮」 | 启动·停止·重启；强杀端口僵尸；状态：未装/已停/运行中/异常 | 不叠多实例 |
| 5 | **监控日志** | 「出问题看得见」 | 尾部日志面板或「打开日志」；级别过滤；复制路径 `show_saved` 友好 | 进页不卡；日志可关 |
| 6 | **版本备份** | 「升坏了能回去」 | 升级前快照可回滚；展示当前版本/钉扎版本；备份目录可打开 | 至少能回到上一可用版 · **`harness_agent` 已落地**（更多/环境维护「备份系统」+ 更新前自动备份） |

**同一套 Host 壳（每个引擎页同构）**

```text
[状态灯]  名称 · 版本
[启动|停止] [在浏览器打开★] [更多▾]
更多：修复 · 卸载 · 版本备份/回滚 · 打开日志 · 打开安装目录 · 改内嵌(可选)
```

- ★ **在浏览器打开** = 干重活主 CTA（C-11 已落地于 Harness）  
- 安装未完成时：主区仍是三步门（装→Key→启），六件套中「卸/修/备份」在装上后解锁  

**首条样板**：`harness_agent` 已有装/启停/干净重启/浏览器 CTA → 按上表补齐 **卸 / 修 / 日志面板 / 版本备份**，再复制到 Comfy 等条目。

### 3.3 P0 · 与收录目录的衔接

| 目录动作 | 落到六件套 |
|----------|------------|
| 条目「安装」 | → 一键安装 |
| 已安装条目 | → 进该引擎 Host 页（启停/日志/…） |
| 条目「移除」 | → 一键卸载 |
| 「更新」 | → 备份当前版 → 装新版；失败可回滚 |

### 3.4 P0 · 办公传送门（套件本分）

| 功能 | 说明 |
|------|------|
| Wave★ 日活 | 剪贴板、截图、记事、任务做强到「敢每天用」 |
| 投喂 | 「送入记事」「送到智能体/浏览器」；链式提示不强制跳转 |
| 本地资产 | `data/` · `output/`；生成 `show_saved` |
| 系统介入 | 热键 / 托盘 / Esc 可退覆盖层 |

### 3.5 P1 · 扩展与增长入口

保持 doc 29：扩展中心在桌面登记需求与生命周期；**实现**可交浏览器 Agent。桌面负责投喂 skill / 打开目录。

### 3.6 明确延期（不做）

| 项 | 说明 |
|----|------|
| **费用管理 / 算力账单** | 本机账本、预算、超限策略、厂商账单汇总——**先不做** |
| 多平台省钱路由大盘 | 随费用延期 |
| Harness | **默认套件内嵌**；外开自点；能力不及处提示「浏览器打开效果更佳」 | 禁止自动弹浏览器；WebEngine ≠ 完整 Chrome |
| 万能脚本市场（任意 URL 乱装） | 仅可信收录清单 |

## 4. 信息架构（建议）

```text
引擎
  ├─ 开源目录 / 收录     ← 好 + 一键装入口
  ├─ 编码智能体          ← 六件套样板 +「浏览器打开」★
  └─ Comfy / Draw.io …  ← 同构 Host（装齐后再复制）

办公
  ├─ 剪贴板 / 截图 / 记事 / 任务  ← 传送门
  └─ …

系统
  ├─ 算力来源（轻量绑 Key，若已有）  ← 不做账单页
  └─ 扩展 / 主题 / 热键 …
```

首页文案口径建议：**「办公传送门 · 开源引擎一键管（装卸修启停）」**；勿写「算力与费用统一管」。

## 8. 风险与边界

| 风险 | 应对 |
|------|------|
| 收录变成「随便下脚本」 | 仅可信清单；安装路径沙箱化 |
| 一键装变运维泥潭 | 先 Harness 做深六件套，再复制；宁少勿滥 |
| 卸载误删用户作品 | 卸载默认保留工作区/会话；勾选才清数据 |
| 日志吓到小白 | 默认折叠；「出问题时点开」；人话摘要 + 原文 |
| 备份占盘 | 默认保留 N 代（实现再定）；可「打开备份目录」自删 |
| 用户仍以为桌面要嵌网页 | 默认内嵌；能力不及处提示外开效果更佳 |
| 费用需求回流 | 单独立项；不偷塞进 Host |

## 9. 已拍板 / 仍待细项

**已拍板**

1. 桌面 = 收录 + **生命周期六件套** + 办公传送门  
2. 业务重活 = 浏览器  
3. **费用管理先不做**  
4. Agent / Harness：**默认套件内嵌**（ARCH-05）；外开须自点；能力不及处提示「浏览器打开效果更佳」  
5. 六件套要**穿成一条 UX**，宁少做深（先 Harness）再复制  

**实现时再定（不阻塞方向）**

- 收录清单配置格式与是否独立菜单 id  
- 首批收录条目名单（Harness / Comfy / …）  
- 内嵌预览是否保留为高级开关  
- 版本备份保留几代、是否压缩
