# ARCH-06 · 菜单 → 产品方案 → 支付 → 授权（信息链条）

> **状态**：主理人裁定 · 2026-08  
> **原则**：稳、准、安全 — 每一环可追溯、不可篡改、履约前校验  
> **体验/付费分层**：见 [`ARCH-04-授权与单机联网.md`](ARCH-04-授权与单机联网.md)（旧 25 已归档）

---

## 1. 目标链条

```text
① 终端管理员 · 设置·菜单
      │ 保存本机菜单 +「同步目录到运营台」(admin 授权码)
      ▼
② 云服务 · menu 目录 DB（module 池）
      │ 运营台「产品方案」= 功能选配 + 有效期 + 定价
      ▼
③ 云服务 · toa_feature_packs DB（方案 SKU，API 别名 plan_id）
      │ 用户选方案下单（金额=定价快照，有效期=方案 validity_days）
      ▼
④ 支付（mock / webhook，幂等 payment_ref）
      │ 校验：金额=定价、module 均已发布、方案可售
      ▼
⑤ 一订单一授权码（新建 license 行，不合并同手机号旧码）
      │ menus_json = [plan_id]（TOA3 端展开 module）
      ▼
⑥ 终端 activate/check → access_control.can_open(module_id)
```

| 环节 | 真相源 | 维护者 |
|------|--------|--------|
| 菜单 module 池 | 云 DB `toa_menu_modules` | **终端管理员** 同步 |
| 产品方案 | 云 DB `toa_feature_packs` | **运营台** 编辑 |
| 功能选配 | 方案 `features_json` / `includes_json` | **运营台** |
| 有效期 | 方案 `validity_days` | **运营台** |
| 定价 | 方案 `price_yuan` | **运营台** |
| 订单金额 | 创建时锁定 = 定价 | 系统校验 |
| 订单有效期 | 创建时锁定 = 方案 `validity_days` | 系统（终端不可改） |
| 授权范围 | `plan_id` 签发 | 支付履约（每单新码） |

**术语**：对外称 **产品方案**；`pack_id` 为历史兼容别名，与 `plan_id` 同值。

---

## 2. 安全门禁

| 校验点 | 规则 |
|--------|------|
| 菜单发布 | 须 **admin 授权码** + `machine_id` 匹配 |
| 组方案 | 只能选 **已发布** module_id |
| 下单 | `amount_yuan` **必须等于** 方案定价；`license_days` 来自方案 |
| 履约 | 再次校验定价 + module 对齐；`payment_ref` 幂等 |
| 一订单一码 | 每次履约 **新建** `toa_licenses` 行，绑定 `order.license_id` |
| 授权码 | HMAC 签名；`menus_json` 只存 **plan_id** |
| 桌面开门 | `can_open` 展开方案，不读运营台菜单 IA |

---

## 3. 运维命令

**开发/bootstrap**（首次灌库，之后以 DB 为准）：

```powershell
powershell -File toa-cloud/scripts/sync_toa3_product_catalog.ps1
```

**日常**：

1. 终端管理员：设置·菜单 → 保存 → **同步目录到运营台**
2. 运营台：产品方案 → 编辑/新建 → 勾选 module + 有效期 + 定价
3. 用户：选方案下单 → 支付 → 激活该订单授权码

发版前本地：

```bash
python scripts/verify_feature_packs_menu.py
```

---

## 4. API 摘要

| API | 用途 |
|-----|------|
| `POST /api/toa/menu-catalog/publish` | 终端管理员上传 module 目录 |
| `GET /api/toa/menu-catalog/modules` | 运营台组方案可选列表 |
| `GET /api/toa/plans` | 终端拉取可售产品方案（`/packs` 兼容） |
| `PUT /api/toa/packs/{id}` | 保存方案 + 定价 + modules + validity_days |
| `POST /api/toa/orders` | 创建订单（`plan_id`，金额=定价） |
| `POST /api/toa/orders/by-no/{no}/pay` | 终端支付履约 → 一订单一授权码 |

---

## 5. 不做

- 运营台在线改侧栏 IA（仍由终端菜单 + 发版带走）
- 终端用户编辑方案/定价
- 终端「授权管理」展示方案 SKU 对照表（见本文后文「原分册：23」）
- 订单金额与定价不一致仍履约
- 同手机号续费合并换码（已改为每单新码；续购 = 新订单 + 新授权码）

# 23 · 运营台与终端设置职能边界

> **状态**：主理人裁定 · 2026-08  
> **关联**：本文前半「原分册：22」· [`ARCH-04-授权与单机联网.md`](ARCH-04-授权与单机联网.md)

---

## 1. 总原则

| 原则 | 说明 |
|------|------|
| **一条真相源** | 同一数据只在一处维护；另一处只读或跳转，不复制编辑能力 |
| **终端 = 本机体验 + 本机 IA** | 侧栏菜单、本机品牌、本机用户、本机 Key、购买/激活 |
| **运营台 = 商业与履约** | SKU、定价、订单、发码台账、版本发布、全局审计 |
| **禁止** | 终端展示「产品方案 SKU 编辑/对照表」；运营台在线改侧栏 IA |

运营台入口：`https://toa-service.yczh.tech/admin/app.html`

---

## 2. 职能对照表（截图页面对应）

### 2.1 系统设置 · 页签级（2026-08 收敛 v3 · 运营台归组）

| 页签 / 分组 | 谁看 | 做什么 |
|------|------|--------|
| **系统** | 全体 | 版本、检查更新、关于、重启/退出；管理员可切换身份 |
| **偏好** | 全体 | 主题、快捷键 |
| **模型管理** | 全体 | 模型列表与 Key（独立页签，不在偏好内） |
| **运营台与商业**（分组） | 全体可见「运营台」；管理员另见授权/菜单；未授权见开通 | **运营台**一键打开 `…/admin/app.html`；**授权**本机用户；**菜单**可见性与同步目录；**开通与续费**未授权时 |
| **本机维护**（分组） | 管理员 | 品牌 · 能力接入 · 诊断（见 `app.yml` · `settings_menu`） |

### 2.4 顶栏入口（用户心智）

| 入口 | 内容 | 不含 |
|------|------|------|
| **授权 Chip** | 权限不够 → 买；已授权 → 摘要 | SKU 编辑 |
| **系统设置**（齿轮 · Alt+S · 系统侧栏） | 左侧分区菜单 + 首项「系统」 | 账号退出 |
| **切换身份**（Alt+U） | 仅管理员；入口在「系统设置 → 系统」 | 顶栏/普通用户 |
| **账号（人像）** | 查看、退出 | 开通/维护 |
| **关于**（ℹ · Alt+Shift+O） | 愿景、版本、检查更新 | 授权名单编辑 |
| **运营台 · 账号/办公插件/流水** | 平台启用停用、上架下架、无偿流通审计 | 代写用户业务扩展 |

顶栏右侧仅 **设置 · 关于 · 用户**；主题/全屏/命令面板/切换身份仍可用热键或系统设置内入口。

### 2.2 授权管理 · 子页（原三 Tab 收敛为二）

| 子页 | 归属 | 做什么 | 不做什么 |
|------|------|--------|----------|
| **授权用户** | 终端 | 本机多用户名单、本机发卡/编辑/吊销、同步名单到云 | 不看订单、不改 SKU、不做定价 |
| ~~运营参考~~ | **已移除** | — | 菜单对照、产品方案 SKU 表 → **只在运营台** |
| **云服务连接** | 终端 | 只读 API 地址、机器 ID、复制绑机 | 不改云配置、不编辑产品方案 |

### 2.3 运营台 · 模块级

| 模块 | 归属 | 做什么 | 不做什么 |
|------|------|--------|------|
| **概览 / 审计** | 运营台 | 订单、授权、试用全局视图 | 不改本机侧栏 |
| **产品方案** | 运营台 | 功能选配 + 有效期 + 定价、上下架 | 不定义 module 从哪来（来自终端同步） |
| **菜单目录** | 运营台 | **只读** 终端同步的 module 列表 | 不在线下发侧栏 IA |
| **订单 / 支付** | 运营台 | 创建、履约（一订单一授权码）、webhook | 不在终端重复订单台 |
| **授权 / 试用台账** | 运营台 | 商业发码、到期、审计 | 不替代本机「授权用户」日常运维 |
| **版本发布** | 运营台 | manifest、安装包、Portal 下载 | 不在终端发版 |

## 3. 信息链条（谁写谁读）

```text
终端·菜单 ──publish──▶ 云·module 目录 ──只读──▶ 运营台·组方案
                              │
终端·一键购买 ◀──order/pay── 运营台·产品方案（选配+有效期+定价）
                              │
终端·activate ◀──license_key── 运营台·履约发码（每单新码）
                              │
终端·授权用户 ──sync──▶ 云·名单（校验/审计）
终端·联网校验 ◀──pull── 云·最新授权状态
```

## 4. 用户路径（避免职能打架）

| 用户意图 | 正确入口 | 错误入口 |
|----------|----------|----------|
| 买套餐 / 续费 | 拦截弹窗 · 设置·运营台与商业 · 顶栏 Chip | 授权管理里找 SKU 表 |
| 进运营台发版/订单 | 设置·运营台与商业 → 运营台（`…/admin/app.html`） | 散落在系统/关于页 |
| 改侧栏有哪些功能 | 设置·菜单（同组「运营台与商业」） | 运营台在线改侧栏 |
| 改方案内容、有效期和价格 | 运营台·产品方案 | 终端设置 |
| 给同事发本机子账号 | 设置·授权管理·授权用户 | 运营台（除非商业新购） |
| 看 module 能否组包 | 运营台·菜单目录 | 终端「运营参考」 |
| 绑机器 / 复制 machine_id | 设置·授权管理·云服务连接 | — |
| 换 Logo / 品牌名 | 设置·品牌定制 | 运营台 Portal 叙事（不同层） |

## 5. 终端 UI 已做收敛（2026-08）

- 删除 **授权管理 → 运营参考**（菜单授权对照、产品方案 SKU 只读表）
- 设置页眉文案区分「终端管理员」与「终端用户」职责
- **开通与续费** 与 paywall 弹窗共用 `purchase_pack()` / `purchase_plan()` 一键链路（一订单一授权码）

## 6. 不做

- 终端内嵌运营台 SKU 编辑器
- 运营台修改 `data/user/menu.yml` 或侧栏排序
- 两处同时维护 `feature_packs.yml` 定价（定价真相源：云 DB）
