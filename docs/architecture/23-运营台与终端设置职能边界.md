# 23 · 运营台与终端设置职能边界

> **状态**：主理人裁定 · 2026-08  
> **关联**：[`22-菜单与功能包分层维护.md`](22-菜单与功能包分层维护.md) · [`16-TOA授权与单机联网模式规划.md`](16-TOA授权与单机联网模式规划.md)

---

## 1. 总原则

| 原则 | 说明 |
|------|------|
| **一条真相源** | 同一数据只在一处维护；另一处只读或跳转，不复制编辑能力 |
| **终端 = 本机体验 + 本机 IA** | 侧栏菜单、本机品牌、本机用户、本机 Key、购买/激活 |
| **运营台 = 商业与履约** | SKU、定价、订单、发码台账、版本发布、全局审计 |
| **禁止** | 终端展示「功能包 SKU 编辑/对照表」；运营台在线改侧栏 IA |

运营台入口：`https://toa-service.yczh.tech/admin/`

## 2. 职能对照表（截图页面对应）

### 2.1 系统设置 · 页签级

| 页签 | 归属 | 维护者 | 说明 |
|------|------|--------|------|
| **外观与主题** | 终端 | 终端用户 | 本机 UI 偏好 |
| **品牌定制** | 终端 | 终端管理员 | 本机白标（`data/user/system_info.json`），非运营台产品默认 |
| **授权管理** | 终端 | 终端管理员 | **仅**本机用户名单 + 云服务连接；不含 SKU/定价 |
| **激活与订阅** | 终端 | 终端用户 | 一键开通/续费；未授权时显示 |
| **菜单** | 终端 | 终端管理员 | 侧栏 IA；同步 **module 目录** 到云（非运营台改菜单） |
| **快捷键** | 终端 | 终端用户 | 本机热键 |
| **能力接入** | 终端 | 终端管理员 | 本机 integrations / 模型 Key |
| **运行诊断** | 终端 | 终端管理员 | 本机日志与健康 |
| **关于与应用** | 终端 | 全体 | 版本、检查更新、退出 |

### 2.2 授权管理 · 子页（原三 Tab 收敛为二）

| 子页 | 归属 | 做什么 | 不做什么 |
|------|------|--------|----------|
| **授权用户** | 终端 | 本机多用户名单、本机发卡/编辑/吊销、同步名单到云 | 不看订单、不改 SKU、不做定价 |
| ~~运营参考~~ | **已移除** | — | 菜单对照、功能包 SKU 表 → **只在运营台** |
| **云服务连接** | 终端 | 只读 API 地址、机器 ID、复制绑机 | 不改云配置、不编辑功能包 |

### 2.3 运营台 · 模块级

| 模块 | 归属 | 做什么 | 不做什么 |
|------|------|--------|------|
| **概览 / 审计** | 运营台 | 订单、授权、试用全局视图 | 不改本机侧栏 |
| **功能包** | 运营台 | 从已发布 module 池组包、定价、上下架 | 不定义 module 从哪来（来自终端同步） |
| **菜单目录** | 运营台 | **只读** 终端同步的 module 列表 | 不在线下发侧栏 IA |
| **订单 / 支付** | 运营台 | 创建、履约、webhook、发码 | 不在终端重复订单台 |
| **授权 / 试用台账** | 运营台 | 商业发码、到期、审计 | 不替代本机「授权用户」日常运维 |
| **版本发布** | 运营台 | manifest、安装包、Portal 下载 | 不在终端发版 |

## 3. 信息链条（谁写谁读）

```text
终端·菜单 ──publish──▶ 云·module 目录 ──只读──▶ 运营台·组包
                              │
终端·一键购买 ◀──order/pay── 运营台·SKU+定价
                              │
终端·activate ◀──license_key── 运营台·履约发码
                              │
终端·授权用户 ──sync──▶ 云·名单（校验/审计）
终端·联网校验 ◀──pull── 云·最新授权状态
```

## 4. 用户路径（避免职能打架）

| 用户意图 | 正确入口 | 错误入口 |
|----------|----------|----------|
| 买套餐 / 续费 | 拦截弹窗 · 设置·激活与订阅 · 顶栏 Chip | 授权管理里找 SKU 表 |
| 改侧栏有哪些功能 | 设置·菜单 | 运营台 |
| 改套餐内容和价格 | 运营台·功能包 | 终端设置 |
| 给同事发本机子账号 | 设置·授权管理·授权用户 | 运营台（除非商业新购） |
| 看 module 能否组包 | 运营台·菜单目录 | 终端「运营参考」 |
| 绑机器 / 复制 machine_id | 设置·授权管理·云服务连接 | — |
| 换 Logo / 品牌名 | 设置·品牌定制 | 运营台 Portal 叙事（不同层） |

## 5. 终端 UI 已做收敛（2026-08）

- 删除 **授权管理 → 运营参考**（菜单授权对照、功能包 SKU 只读表）
- 设置页眉文案区分「终端管理员」与「终端用户」职责
- **激活与订阅** 与 paywall 弹窗共用 `purchase_pack()` 一键链路

---

## 6. 不做

- 终端内嵌运营台 SKU 编辑器
- 运营台修改 `data/user/menu.yml` 或侧栏排序
- 两处同时维护 `feature_packs.yml` 定价（定价真相源：云 DB）
