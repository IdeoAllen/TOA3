# 22 · 菜单 → 功能包 → 支付 → 授权（信息链条）

> **状态**：主理人裁定 · 2026-08  
> **原则**：稳、准、安全 — 每一环可追溯、不可篡改、履约前校验

---

## 1. 目标链条

```text
① 终端管理员 · 设置·菜单
      │ 保存本机菜单 +「同步目录到运营台」(admin 授权码)
      ▼
② 云服务 · menu 目录 DB（module 池）
      │ 运营台「功能包」勾选 module + 定价
      ▼
③ 云服务 · feature_pack DB（SKU）
      │ 用户选 pack 下单（金额=定价快照）
      ▼
④ 支付（mock / webhook，幂等 payment_ref）
      │ 校验：金额=定价、module 均已发布、pack 可售
      ▼
⑤ 授权码 menus_json = [pack_id]（TOA3 端展开）
      ▼
⑥ 终端 activate/check → access_control.can_open(module_id)
```

| 环节 | 真相源 | 维护者 |
|------|--------|--------|
| 菜单 module 池 | 云 DB `toa_menu_modules` | **终端管理员** 同步 |
| 功能包 SKU | 云 DB `toa_feature_packs` | **运营台** 编辑 |
| 定价 | 功能包 `price_yuan` | **运营台** |
| 订单金额 | 创建时锁定 = 定价 | 系统校验 |
| 授权范围 | `pack_id` 签发 | 支付履约 |

---

## 2. 安全门禁

| 校验点 | 规则 |
|--------|------|
| 菜单发布 | 须 **admin 授权码** + `machine_id` 匹配 |
| 组包 | 只能选 **已发布** module_id |
| 下单 | `amount_yuan` **必须等于** pack 定价 |
| 履约 | 再次校验定价 + module 对齐；`payment_ref` 幂等 |
| 授权码 | HMAC 签名；`menus_json` 只存 **pack_id** |
| 桌面开门 | `can_open` 展开 pack，不读运营台菜单 IA |

---

## 3. 运维命令

**开发/bootstrap**（首次灌库，之后以 DB 为准）：

```powershell
powershell -File toa-cloud/scripts/sync_toa3_product_catalog.ps1
```

**日常**：

1. 终端管理员：设置·菜单 → 保存 → **同步目录到运营台**
2. 运营台：功能包 → 编辑/新建 → 勾选 module + 定价
3. 用户：选包下单 → 支付 → 激活授权码

发版前本地：

```bash
python scripts/verify_feature_packs_menu.py
```

---

## 4. API 摘要

| API | 用途 |
|-----|------|
| `POST /api/toa/menu-catalog/publish` | 终端管理员上传 module 目录 |
| `GET /api/toa/menu-catalog/modules` | 运营台组包可选列表 |
| `PUT /api/toa/packs/{id}` | 保存 SKU + 定价 + modules |
| `POST /api/toa/orders` | 创建订单（金额=定价） |
| `POST /api/toa/orders/by-no/{no}/pay` | 终端支付履约 |

---

## 5. 不做

- 运营台在线改侧栏 IA（仍由终端菜单 + 发版带走）
- 终端用户编辑 SKU/定价
- 终端「授权管理」展示功能包 SKU 对照表（见 [`23-运营台与终端设置职能边界.md`](23-运营台与终端设置职能边界.md)）
- 订单金额与定价不一致仍履约
