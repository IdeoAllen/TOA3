- 首页无 migration StatusDot

### 4.3 Full Go

- 上述 + 主窗 Chip/横幅 CTA + 托盘 menu_registry（Target MVP）

## 5. 不专业设计 · 重规划摘要

### 5.1 术语（P1）

| 禁止（用户可见） | 统一为 |
|------------------|--------|
| TOA2- | TOA 授权码 |
| DMS / 台账 / 判定 | TOA 云服务 / 账号 / 授权状态 |
| 子模块 · 功能模块 | 分类 · 功能 |
| auth.skip_login | （Release 不出现） |

### 5.2 信息架构（P1）

- **设置**：Tab「激活与授权」含 `ActivationSection`；「订阅与续费」独立
- **顶栏**：用户 Chip = 账号 + pack + 剩余天；设置图标语义与快捷键一致
- **关于**：单一路径，愿景块精简

### 5.3 反馈（P1）

- 登录/校验：**单通道**错误（inline 或 toast，禁止三叠）
- 状态栏：左临时消息 / 右永久版本；`StatusLevel` 走 QSS
- 首页：Release 隐藏 migration 灯；横幅带 CTA

### 5.4 托盘 / 升级 Target（P1–P2）

- 托盘：`menu_registry` 分组 + 授权/更新入口
- 升级：后台检查 badge；发现新版本对话框含 changelog + Portal
- 版本号：构建时从 `app/version.py` 单一注入
