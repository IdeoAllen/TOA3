# 19 · AI 子模块分工与多模态模型中枢

> 回答：「大模型助手是干嘛的？」以及生图 / 生视频 / 音频等三方模型的对接与管理形态。  
> 关联：`20-模型库与ComfyUI式就绪列表` · `29-扩展增长中心与模型接入及软资产` · `30-算力来源与支付卡隐喻`（办公轨 vs 开发 Agent 双轨）

## 1. AI 顶栏下三个角色（不要混）

| 模块 | 干什么 | 什么时候用 | 技术底座 |
|------|--------|------------|----------|
| **编码智能体** `harness_agent` | 写代码、改仓库、终端、插件、多轮 Agent | 开发任务、自动化改 TOA、复杂工程 | DeepSeek **Harness**（正版 Web + Sidecar） |
| **大模型助手** `llm_assistant` | 单次文本：润色、摘要、试提示词 | 润色剪贴板、写通知/邮件草稿、快速问一句 | `integrations` · **llm**（OpenAI 兼容 HTTP） |
| **媒体工坊** `media_studio` | 生图 /（规划）生视频、音频 | 配图、短视频素材、配音 | `integrations` · **image_gen**（**本机简易优先** · ComfyUI 专业 · 云端 API） |

**铁律**：

- Harness **不走** `integrations/llm`；密钥在 DSH，与 Harness 官方一致。
- 大模型助手 **不是** 编码智能体的低配版；不承载多轮工程会话。
- 所有云端/本地模型 **只经** `services/integrations`；业务页禁止手写 URL/Key。
- **算力来源**对用户像支付卡（绑定 / 默认 / 解绑）；详见 [30-算力来源与支付卡隐喻](30-算力来源与支付卡隐喻.md)。

## 2. 大模型助手 today

- 页面：提示词框 → 调 `get_client("llm").complete()` → 结果框。
- 配置：**系统设置 → 能力接入 → 大模型**（API 地址、模型名、Key）。
- 还被其它模块间接使用：截图翻译、摘要类能力（同一 `llm` 客户端）。
- 现状 `mvp`：无多轮会话、无流式；适合 **短文本办公**，不是主 Agent 入口。

## 3. 多模态扩展目标（专业、流畅）

### 3.1 用户心智（小白）

```
选能力（生图 / 生视频 / 配音）
  → 选已配置的模型（带状态：可用 / 未配置）
  → 填输入（文案 / 参考图）
  → 生成 → 文件落到 output/，绿色完成 + 打开目录
```

不在业务页堆 API 表单；**配置在设置，任务在模块**。

### 3.2 架构（与现有 integrations 一致）

```
modules/media_studio/          # 唯一任务页（或按能力子页签）
        ↓
services/integrations/
  image_gen_client.py          # 例：SD WebUI / DALL·E / 通义万相
  video_gen_client.py
  audio_gen_client.py
        ↓
config/model_catalog.yml         # 能力 → profiles（网络/本地端点）
data/user/model_catalog.yml      # 用户 active + 自定义 profile
```

**模型库（ComfyUI 式 Ready 列表）**：详见 [20-模型库与ComfyUI式就绪列表](20-模型库与ComfyUI式就绪列表.md)。任务页只选 `ready`；安装包不含权重。

```
config/integrations.yml        # 开关 + 端点 + 默认模型
data/user/integrations_secrets.json
```

每个 Client：

- `health_check()` — 设置页点「测试」时才联网，**进页禁止探测**。
- `list_models()` / `generate(...)` — 领域方法，返回本地文件路径。

### 3.3 设置页演进：「模型目录」

在 **能力接入** 内由「按技术分 Tab」升级为 **按能力分卡片**：

| 卡片 | 内容 |
|------|------|
| **模型库** | Ready / 待密钥 / 待端点 / 待下载 总览（ComfyUI 式） |
| 文本大模型 | 多 profile 配置 + Key |
| 编码智能体 | 现有 Harness Tab |
| 图像生成 | 提供商下拉 + 端点 + Key + 默认模型 + 测试 |
| 视频生成 | 同上 |
| 语音 / 音频 | TTS、配音、转写（按需） |
| 连通总览 | 各能力一行状态 |

同一提供商（如 OpenAI 兼容网关）可 **复用 Key**，在 catalog 里声明 `shared_secret: llm`。

### 3.4 菜单与壳层

- **AI 子模块侧栏**（建议终态）：
  - 编码智能体
  - 大模型助手（保留，轻量文本）
  - 媒体工坊（`media_studio`，生图/视频/音频统一入口）
- 隐藏或降级：`image_creator`（纯色占位）→ 由媒体工坊替代。

### 3.5 验收口径（做多模态时）

1. 新增提供商只改：`integrations.yml` + Client + registry + 设置卡片，**不改壳层**。
2. 未配置时：任务页明确「去设置配置 XX」，不出现裸 API 错误码。
3. 生成完成一律 `show_saved` + `output/` 可追溯。
4. 进页 / 热键路径无同步联网卡 30s。

## 4. 实施顺序（建议）

| 阶段 | 交付 |
|------|------|
| P0 | `model_catalog.yml` 草案 + 设置页「图像生成」第一张卡片（单提供商） |
| P1 | `media_studio` 页：文生图主路径 + 导出 |
| P2 | 视频 / 音频 Client + 工坊内能力切换 |
| P3 | 本地模型（ComfyUI / Ollama 图像）与云端并列可选 |
| **P1′（图像阶梯）** | **L1 本机简易**（sd.cpp + Z-Image GGUF，零工作流）→ L2 ComfyUI → L3 云端；详见 [20](20-模型库与ComfyUI式就绪列表.md) §图像三级阶梯 |
