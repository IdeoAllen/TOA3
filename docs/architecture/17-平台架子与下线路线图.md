## 1. 目标架子（一张图）

```text
                    Portal（www.yczh.tech）
                    介绍 · TOA3 下载 · 购买说明
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    TOA 云服务          TOA3 桌面         DMS Web
    授权/订单/发码      单机+联网          免费交付
    （Portal 后端）     商业产品           企微建群/通知
           ▲               │               │
           └──── 仅 TOA3 联网校验 ─────────┘
                         无强绑定
```

| 组件 | 是什么 | 收费 | 下线/替换 |
|------|--------|------|-----------|
| **TOA3** | Windows 运营宝（PySide6） | 商业 | **替换 TOA2** |
| **TOA2** | 旧 tkinter 版 | — | **下线**，只留紧急修 |
| **DMS** | 交付材料 Web | **免费** | 保留；吸收 WCS 必要能力 |
| **TOA 云服务** | 授权/试用/订单/发码 API + 运营台 | — | **新建**（从 DMS 迁出 toa_license） |
| **Portal** | 静态入口 + 下载 + 购买页 | — | 保留；叙事改为双产品 |
| **WCS** | 企微智能客服 | — | **下线**；建群/通知已在 DMS |

---

## 2. 边界（三句记牢）

1. **DMS 与 TOA 两套产品，无强绑定** — 不共用登录、不共用菜单、DMS 不收 TOA 的钱。  
2. **TOA 商业全在 Portal 侧 TOA 云服务** — 激活、试用、购买记录、发码；桌面只缓存 `license.json`。  
3. **WCS 能力能迁 DMS 的已迁** — 其余（FAQ bot、定时播报）不迁则关。

---

## 3. 下线路线图

### 3.1 TOA2 → TOA3

| 阶段 | 动作 |
|------|------|
| 现在 | TOA3 主开发；Portal 下载改 TOA3；TOA2 标「已停止新功能」 |
| 发版 | Inno 安装包；Portal `/downloads/` 只挂 TOA3 |
| 收尾 | TOA2 仓库封板；手册删 TOA2 安装说明 |

### 3.2 WCS → DMS（必要功能）

| 能力 | 状态 |
|------|------|
| 建群 / 绑群 / 事件通知 | ✅ DMS |
| 企微 OAuth / JS-SDK | ✅ DMS |
| 智能客服 / 知识库 / 定时播报 | ⬜ 不迁则随 WCS 关 |
| DMS↔WCS 绑群同步 | ⬜ Phase1 停同步（见 doc 15） |

### 3.3 TOA 授权 DMS → TOA 云服务

| 阶段 | 动作 |
|------|------|
| 配置 | `license.service_url`（目标）；`dms_base_url` 过渡只读 |
| 服务 | 迁 `toa_licenses` + API 到 Portal 后端 |
| 客户端 | TOA3 `license_client` 只连 service_url |
| DMS | 「运营助手授权」改外链或删除 |

## 4. 各仓库职责（Agent 起手式）

| 仓库 | 只做什么 |
|------|----------|
| **TOA3** | 桌面、feature_packs、access_control、连 TOA 云服务 |
| **DMS** | 交付业务、企微触达、免费 Web；**不做** TOA 商业 |
| **Portal** | 首页叙事、TOA3 下载、购买页、Surface TOA 运营台 |
| **TOA2** | 封板，不新功能 |
| **WCS** | 冻结，归档 |

## 5. 配置真相源（TOA3）

```yaml
license:
  service_url: https://toa-service.yczh.tech/api/toa-license
  dms_base_url: https://dms.yczh.tech   # 过渡 fallback
update:
  manifest_url: https://toa-service.yczh.tech/api/toa/releases/manifest?product=TOA3&channel=stable
  download_page: https://www.yczh.tech/downloads/
```

**域名**：`https://toa-service.yczh.tech`（与 Portal / DMS 独立）

仓库：`toa-cloud/`

| 能力 | 说明 |
|------|------|
| 授权 API | `https://toa-service.yczh.tech/api/toa-license/*` |
| 运营台 | `https://toa-service.yczh.tech/admin/` |

| 终端升级 | 关于页检查更新 → 打开下载（非静默安装） |
