## 阶段 P3 — 业务模块批次

按 `Agent起手式.md` 阶段 C 顺序迁移；每模块：

- `BasePage` + `storage.yml` + `MIGRATED_MODULES`
- 状态/异常只用平台 API
- `verify_all` 绿

## 开发约定（平台 API）

```python
# 状态（状态栏 + 日志）
self.report_status("完成", level=StatusLevel.SUCCESS)

# 弹窗（禁止 QMessageBox）
from core.user_messages import show_info, show_error, ask_confirm
from core.error_handler import report_error, run_safe

# 审计
from core.audit_log import audit, log_action

# 系统信息
from services.system_info import get_system_info, logo_path
```

## 验收
