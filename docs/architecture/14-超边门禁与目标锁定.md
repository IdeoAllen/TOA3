## 2. 分层与依赖（只允许向下）

```
modules 业务页
  → widgets + ui
  → app shell + core
  → services（含 integrations）
  → config + themes JSON
```

| 层 | 做什么 | 禁止 |
|----|--------|------|
| `modules/` | BasePage、绑信号、调 services、展示结果 | setStyleSheet/硬编码色、直连 HTTP、自建壳/侧栏、裸 QMessageBox |
| `widgets/` + `ui/` | 唯一控件来源；Designer 布局 | 引用具体业务模块；ui 里写业务 IO |
| `app/` + `core/` | 壳、主题、弹窗规格、异常 | 写具体业务规则 |
| `services/` | 无 UI 领域能力；integrations 统一外呼 | import 业务页；业务旁路 URL |
| `config/` | yaml/json 真相源 | 手改生成 QSS |

TOA2：只读对照；**迁逻辑、不迁 tk UI**；禁止回写 TOA2。

## 3. 「超边代码」判定表（写码/合入禁入）

凡落入下表即超边，**不得合入主线**（已注释的控件库例外除外，且不得扩大）。

| 类别 | 超边表现 | 正确落点 |
|------|----------|----------|
| 样式 | 业务页 `setStyleSheet`、硬编码 hex、裸主按钮 | 全局 QSS + `widgets/`；例外须 `# 控件库例外：` |
| 弹窗 | 裸 `QMessageBox` / 未居中自绘 `QDialog` | `BaseDialog` / `user_messages` + `center_on_screen` |
| 窗口 | 业务页自定宽高绕过规格 | `config/ui_spec.yml` |
| 三方 | `modules` 内 `requests`/`urllib` 打外网 | `services.integrations.get_client` |
| 路径 | 手写 `../data`、乱写系统目录 | `storage_paths` + `storage.yml` |
| 菜单 | `shell`/`home` 写死工具列表 | `app.yml` / `user/menu.yml` |
| 壳 | 模块内第二套顶栏/侧栏/`QTabWidget` 外壳 | 仅 `MainShell` + Stack |
| 仓库 | 改 TOA2 业务 UI；或 TOA3 逻辑回写 TOA2 | TOA3 重写 |
| 性能 | 进页/热键同步联网探测 | 懒加载；探测放设置显式动作 |
| 优先级 | 未过截图/八件套就开培训凑数、空菜单 stub 假绿灯 | Wave★ 顺序 + manifest 诚实 gaps |
| 状态 | 有 gaps 标 `done` | 主理人认可且 gaps 空 |

## 4. 合入前自检（每 PR / 每模块）

```text
[ ] 未新增业务 setStyleSheet / 硬编码色（或已注释合法例外）
[ ] 无裸 QMessageBox；新弹窗走 BaseDialog
[ ] 无 modules 直连 HTTP
[ ] 路径走 storage_paths；菜单走 yaml
[ ] 未改 TOA2；未跳 Wave★ 顺序
[ ] Top3 approved（若增强/新建）
[ ] verify_all + audit_migration + audit_architecture 通过
```

**双门禁**：功能增强 = Top3 + 三独到处（主理人确认）**且** 超边自检通过。
