发版单点维护

manifest 仅在此登记；部署脚本不再自动改版本
  1. 上传安装包 → /download/（服务器 /opt/toa-cloud/download/，脚本 cloud/deploy/upload_installer.ps1），文件名 TOA3-Setup-v{版本号}.exe
  2. 试链 → 确认直链可下载（本页「发布新版本」内可试链）
  3. 运营台发布 → 填写版本号与更新说明，勾选「设为当前版」
  4. 验收 → 桌面「关于 → 检查更新」或下方 manifest 预览
